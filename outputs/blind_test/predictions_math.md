## M1-21-A-T17

**problem_geometry**
- `representation_issue`: 极限写成两项之差，而两项各自以"分母一阶消失、分子趋于 1"的形式给出；决定极限的发散项对消被藏在"差"里，没有集中在任何一个单一对象上。
- `coupling`: 变限积分与分母 `e^x-1` 以乘积形式绑在一起；两个分母（`e^x-1` 与 `sin x`）形式不同，无法直接通约，导致两项不能逐项处理。
- `scale_competition`: 分子分母中同时存在多个同阶（一阶）机制；两个分母都是一阶零点，主导项必须精确相消，真正的首个非零阶在展开之前不可见。
- `information_risk`: 对任一因子使用等价无穷小（分母 ~ x）会不可逆地丢掉决定极限的那一阶信息——丢掉的正是唯一需要的东西。
- `dependency_structure`: 分子含变限积分，其局部展开的阶依赖积分上限的阶；先展开哪一项、展开到第几阶，决定了后续阶能否匹配。

**main_obstacle**
两项各自都是"1/0 型"的发散量，极限存在完全依赖它们的**精确对消**；但对消的**深度**（相消到第几阶才出现非零项）在题面里不可见，必须在统一表示下把两个（三个）机制展开到**同一阶**才能暴露。难点的结构是"信息被发散性掩盖 + 展开深度未知"，不是"要会算极限"。

**trigger_candidates**
1. 看到两个分式各自的分母在 x→0 时一阶消失、分子趋于 1（即两项各自 ~1/x），而题目要求的是它们**之差**的极限 → 警觉：主导发散项必须精确对消，极限值由对消后的首个非零阶决定，绝不可对任一项单独做等价替换。
2. 看到分子里出现变限积分 `∫_0^x e^{t^2}dt`，且被积函数 `e^{t^2}` 的原函数非初等 → 警觉：不能求原函数，只能在 0 附近做局部展开；且展开阶必须与分母的阶匹配到同一层。
3. 看到两项的分母不同（`e^x-1` 与 `sin x`）→ 警觉：不把两项统一到同一局部表示（同一商或同一展开阶），对消在纸面上"看不见"，只能靠记忆公式硬拼。
4. 看到 `e^x-1` 而不是 `x`、看到 `sin x` 而不是 `x` → 警觉：这里没有可用的等价替换捷径，替换一次就丢掉一阶信息。

**predicted_first_transition**
- `before_state`: 一个"两个各自发散的项之差"的极限；发散项的对消散落在两项之间，任何单边估计都无法判定极限是否存在。
- `operation`: `STATE_REREPRESENTATION` —— 把两项并成**一个商**（统一分母），使"分子 → 0 的对消"成为一个单一对象内部的结构，从而可被展开和比较。
- `after_state`: 问题变成"单个分子在 0 附近的首个非零阶是什么、它相对分母的阶是多少"；极限的存在性被转化为分子与分母的阶的比较。
- `why`: 题面可观察：两项各自 ~1/x（发散），而差有极限 → 对消必然发生；对消只有在同一对象内部才能被定位。
- `basis`: from_problem_statement
- `trope_component`: medium（"通分"是常规动作，但这里是由发散对消结构逼出来的）
- *备选读法*：不并成商，而是把 `1/(e^x-1)` 与 `1/sin x` 各自作为局部洛朗展开处理，再逐阶相减——结构效果相同（都在"匹配到同一阶"），但省掉了一次通分。

**predicted_second_transition**
- `before_state`: 单一商形式；分子是两个（三个）机制的差，其相消深度未知。
- `operation`: `CRITICAL_SCALE_PROBE` —— 把分子各组成项展开到**恰好能暴露首个非零阶**的深度，并确定该阶；同时确认分母的阶与之匹配。
- `after_state`: 分子与分母的首个非零阶都已知，极限由这两个阶的比值决定；不再需要任何近似替换。
- `why`: 题面可观察：一阶项必然相消（否则极限不存在），所以必须探到一阶之后；而 `e^{t^2}` 的展开与 `sin x`、`e^x` 的展开都提供任意阶信息。
- `basis`: from_problem_statement
- `trope_component`: low（"找到首个非零项"是被对消结构直接逼出来的，不是套路选择）

**prior_exposure_self_report**
weak-to-moderate。我对 2021 年这道"变限积分 + 两个分式相减"的极限题有模糊的印象，但不记得标准解的具体步骤；上面两条 transition 的结构读法（对消深度未知 → 统一表示 + 探阶）是从题面直接读出的。

**uncertainty**
最没把握的是 **first_transition 的具体形式**：标准解完全可能不"通分"，而是直接把两个分母各自展开成洛朗级数再逐阶相减（我列出的备选读法）。若如此，我的 T1 会被判 PARTIAL_HIT 而不是 HIT——因为"统一表示"这一步在标准解里可能根本不存在。第二没把握的是 T2 里我默认"展开到二阶即可收口"，但我没有在预测里给出阶数，只给了"探到首个非零阶"的动作描述；如果标准解的做法是先做变量替换再展开，动作名也会不同。

## M1-24-A-T19

**problem_geometry**
- `representation_issue`: 目标是一个关于 f 与"两端点值组合"的**上界**；而 f 只以"二阶导有界"这种局部、粗粒度的信息给出。必须先找到一种把"两端点信息 + 导数匹配条件"翻译成对 f 的表示，才能谈界。
- `redundant_freedom`: f 的形状除了 `f(0)`、`f(1)`、`f'(0)=f'(1)` 与 `|f''|≤1` 之外完全自由 → 自由度极大，目标必须对所有这样的 f 一致成立。
- `coupling`: `f(0)`、`f(1)`、`f'(0)`、`f'(1)` 与 f 在内部的取值被同一个约束绑在一起；只用一个端点的信息无法定出内部偏差。
- `scale_competition`: 右端 `x(1-x)/2` 在两端消失、在中间最大 → 误差允许在端点附近退化；二阶余项（~ 距离²）与端点权重之间存在阶的匹配问题。
- `information_risk`: 一旦丢掉 `f'(0)=f'(1)` 这个**等式**（例如只用单端 Taylor），两端的局部表示就不再共享同一个线性系数，可消去的未知量变成两个，界无法收口。
- `dependency_structure`: 第 (2) 问的被积对象正是第 (1) 问的组合量 → (2) 依赖 (1) 的点态界，是"局部 → 全局"的累积，不是独立问题。

**main_obstacle**
问题结构是"**用两端点的有限信息约束内部偏差**"：约束是二阶导的全局界（局部信息），目标是内部点上的偏差上界（全局结论），而偏差的表达式里已经写明了参考对象（两端值的线性插值）。难点在于：两端各自能给出一个含**未知系数**的局部表示，而该未知系数在两端是同一个（这正是 `f'(0)=f'(1)` 的作用），必须通过把两个表示组合起来把它**消掉**——消掉之后剩下的余项恰好被权重 × 二阶导界控制。问题不在"要会 Taylor"，而在于"两个表示共享一个未知量，必须消去才能收口"。

**trigger_candidates**
1. 看到目标里出现 `f(0)(1-x) + f(1)x`（两端点值的线性插值/弦）→ 警觉：目标其实是"f 与弦的偏差"，应先把弦减掉，让目标变成一个**两端为零**的对象（齐次化），而不是直接对 f 做估计。
2. 看到右端是 `x(1-x)/2`（两端为零、中间最大、且系数恰是 1/2）→ 警觉：这是"二阶余项 × 两端权重"的形状；权重必须来自两端、且和为 1，单端展开给不出这个形状。
3. 看到条件 `f'(0)=f'(1)`（**导数**在两端相等，而不是函数值相等）→ 警觉：这条等式的功能是让两端的局部表示共享同一个未知线性系数，从而可被消去；它是"可消去性"的燃料，不是装饰条件——减掉弦之后它等价于偏差函数的 `g'(0)=g'(1)`。
4. 看到第 (2) 问的右端是 `1/12`，而 (1) 的组合量正好是被积对象 → 警觉：(2) 是把 (1) 的点态界**积分**（局部 → 全局），不应重新独立证明；同时要警觉"先取绝对值再积分"的顺序（先取绝对值才能用 |∫| ≤ ∫|·|）。
5. 看到题面只给 `|f''(x)| ≤ 1` 而不给 f 的具体形式 → 警觉：证明必须只用这条界，任何依赖 f 具体形状的论证都是错的。

**predicted_first_transition**
- `before_state`: 目标是"f 与两端点值组合之差的界"，而 f 的具体形状未知，只有二阶导界与一个两端导数相等的条件。
- `operation`: `AUXILIARY_OBJECT` —— 减掉弦，定义偏差函数（f 减去两端值的线性插值）作为新的研究对象。
- `after_state`: 问题变成：一个**两端为零**（且两端导数相等）的函数，在 `|g''| ≤ 1` 下，内部点上的绝对值有界；参考对象被吸收进研究对象里，目标右端的两端消失结构与新对象的边界条件对齐。
- `why`: 题面可观察：目标表达式里已经写出了弦；弦的斜率是常数，因此"减弦"把 `f'(0)=f'(1)` 原样转成 `g'(0)=g'(1)`，条件的形式不变 → 这个辅助对象是题面自己提示的。
- `basis`: from_problem_statement
- `trope_component`: low（目标是题面明写的组合量，减弦几乎是唯一读法）

**predicted_second_transition**
- `before_state`: 一个两端为零、两端导数相等的函数，已知二阶导的界，要求内部点的界。
- `operation`: `EXACT_ELIMINATION`（前置 `SPACE_AUGMENTATION`）—— 从**两端各自**写出该函数的局部表示（含同一个未知的一阶系数），再用与目标右端结构相匹配的两端权重把它们线性组合，使那个未知系数**精确相消**；剩下的余项由权重之和与二阶导界控制。
- `after_state`: 未知的一阶系数消失，目标上界只剩"权重 × 二阶导界"的组合，右端形状与题面要求一致；第 (2) 问再对 (1) 的点态界积分即可收口。
- `why`: 题面可观察：右端 `x(1-x)/2` 的两端消失与 1/2 系数，正对应"两个权重的凸组合"；而 `f'(0)=f'(1)` 保证两端表示的线性系数相同，使消去在代数上可行。
- `basis`: from_problem_statement
- `trope_component`: medium-to-high（"两端 Taylor 加权组合"是一门标准技巧；题面右端形状支持它，但我无法排除这是我从技巧库里取来的）

**prior_exposure_self_report**
moderate。2024 年这道"弦偏差 + 二阶导界 + 1/12"的证明题辨识度很高，我怀疑自己见过它的标准解。虽然上面 T2 的加权组合是我在本题面下重新推出来的（右端形状给出了线索），但我不能排除回忆的贡献。**如果评分口径严格，请把本题的 T2 记为 pattern_recall。**

**uncertainty**
最没把握的是 **second_transition 的收口方式**：标准解完全可能不走"两端 Taylor 加权组合"，而走积分余项（Green 核）/两次 Rolle 的路线。若如此，我的 T2 会 MISS，而 T1（减弦）大概率仍然 HIT。第二没把握的是 (2) 是否真的依赖 (1)：也可能存在一条不经过 (1) 的独立积分估计路线（虽然题面把两问排在一起，暗示依赖）。

## M1-25-A-T17

**problem_geometry**
- `representation_issue`: 被积函数以"**两个不同类型因子的乘积**"给出；乘积形式使得任一单因子对应的标准原函数模式都无法直接套用，目标（原函数）在乘积形式下不可读。
- `coupling`: 一个实根型因子（线性）与一个无实根型因子（不可约二次）相乘，两类原函数模式（对数型 / 反正切型）被耦合在同一个乘积里，无法分别处理。
- `dependency_structure`: 分解系数依赖两类因子的搭配（线性因子在二次因子附近的平移关系），分解之后各块的积分次序无关。

**main_obstacle**
难点是**表示与目标不匹配**：被积函数的自然表示（乘积）与可积表示（各类基本原函数之和）不是同一种形式；两个因子的"类型"不同（一个对应实极点、一个对应共轭复极点），所以不存在一个统一替换能一次处理，必须先把乘积解耦成可分别匹配基本模式的加法块，再把无实根的二次因子归约成平方 + 常数的规范形。这是"结构类型不匹配 + 耦合"，不是"要会分部积分"。

**trigger_candidates**
1. 看到分母已经是"一个线性因子 × 一个二次因子"的乘积形式 → 警觉：两类因子对应两类不同的原函数模式，乘积把两者耦合住，需要先解耦成和的形式。
2. 看到二次因子 `x^2-2x+2` 的判别式为负（无实根），且其顶点落在积分区间内部 → 警觉：不能靠实根分区间讨论，必须配方成"平方 + 正数"，归约到反正切/对数导数的规范形。
3. 看到积分区间 [0,1] 上两个因子都无零点（无奇点、区间有限）→ 警觉：这是纯结构问题（分解 + 配方），不需要处理瑕积分；所有难度都在表示上。
4. 看到线性因子与二次因子系数之间的具体搭配（线性因子相对二次因子顶点有一个平移量）→ 警觉：分解后的系数是否"干净"取决于这个平移关系，可能需要先把二次因子配方、再在新变量下看线性因子。

**predicted_first_transition**
- `before_state`: 一个"线性因子 × 不可约二次因子"的乘积型被积函数；没有可用的基本原函数模式，目标原函数在乘积形式下不可见。
- `operation`: `STATE_REREPRESENTATION` —— 把乘积型有理函数改写为**若干更简单分式之和**（按因子类型分块），使每个块各自对应一个基本原函数模式。
- `after_state`: 问题从一个乘积的积分变成若干个"单因子型"分式的积分之和；耦合被移除，各块可独立匹配模式。
- `why`: 题面可观察：分母已给出两个不同类型因子的乘积；乘积是唯一障碍，而积分对加法是可分的 → 解耦方向被题面结构指明。
- `basis`: from_problem_statement
- `trope_component`: **high**（"有理函数 → 部分分式"是教科书头号套路。题面的因子结构确实支持它，但我的选择里套路的成分很高；按口径 2，这条建议计入 pattern_recall）
- *备选标签*：`DEPENDENCY_REORGANIZATION`（"解耦两个因子"）——我无法在无定义的情况下判断哪个更贴。这正是方法论备注里说的"词表无定义"问题。

**predicted_second_transition**
- `before_state`: 若干单因子型分式之和；其中二次因子块的原函数在原始坐标下仍不可读。
- `operation`: `NORMALIZE` —— 对无实根的二次因子配方（平移 + 尺度归约），把它变成规范形"平方 + 1"，从而暴露对数导数型与反正切型两个基本模式；线性因子块直接对应对数型。
- `after_state`: 每个块都落在已知基本原函数模式上，积分退化为模式匹配 + 定限代入。
- `why`: 题面可观察：该二次因子判别式为负且顶点在区间内，配方是唯一能把它归约到实轴上可读形式的动作。
- `basis`: from_problem_statement
- `trope_component`: medium（配方是常规动作，但由判别式与顶点位置强制）

**prior_exposure_self_report**
weak。2025 年（最新一年）的这道有理函数积分题我没有明确的印象；但"有理函数积分"这一题型本身极度模板化，套路成分高（见 trope_component）。

**uncertainty**
最没把握的是 **first_transition 是否真的出现在标准解里**：标准解也可能先做变量替换（把二次因子的顶点平移掉，同时把线性因子变成 `u + 常数`），再做分解——那么"分解"就不是第一步，而"换元"才是，我的 T1 会被判 MISS/PARTIAL。第二没把握的是 T2 的标签选择（`NORMALIZE` vs `STATE_REREPRESENTATION`），这是纯命名歧义，不是结构分歧。

## M1-23-A-T18

**problem_geometry**
- `representation_issue`: 目标（极值）以"**两个因子之积**"给出；f 的符号完全由两个因子各自的符号决定，而两个因子的零集是两条**在原点相切**的曲线。乘积形式把符号结构藏起来了，目标（极值）在乘积形式下不可读。
- `coupling`: x 与 y 通过两个因子耦合；两个零集曲线在原点相切、在另一点横截相交，切点附近两者的**相对阶**（x² 与 x³）决定符号。
- `scale_competition`: 原点附近"y 与 x² 比"和"y 与 x³ 比"是两个不同的尺度；两个零集以不同阶消失 → 存在尺度竞争，且二阶判据在此必然退化（Hessian 行列式为 0），必须换到更高阶的尺度比较。
- `dependency_structure`: f 关于 y 是**二次的**（y² 系数非零）→ 驻点条件 ∂f/∂y=0 可显式解出 y 与 x 的依赖，二维驻点系统可降为一维。
- `information_risk`: 若只用二阶判据（Hessian），在退化点会得到"判据失效/无信息"，极易被误读成"该点不是极值点"或"该点无法判断"——这是一个会产生错误结论的信息缺口，而不是中性缺口。

**main_obstacle**
问题结构是"**极值判定被一个退化点卡住**"：f 是两因子之积，其零集是两条在原点相切的曲线，因此原点必然是驻点，且二阶判据在那里给出零信息；该点附近 f 的符号完全由"点落在两条零集曲线之间的哪一层"决定（三层区域符号交替），所以判定必须换成**尺度比较**（比较 y 与 x²、x³ 的相对阶）。其余驻点处两曲线横截相交，二阶判据可用。难点是"判据在关键点上失效 + 需要读出曲线排列决定的符号分层"。

**trigger_candidates**
1. 看到 f 写成两个因子之积，且两个因子的零集是 `y=x²` 与 `y=x³`（都在原点取零、且**在原点斜率都是 0**）→ 警觉：两条零集曲线在原点**相切** → 该点是退化驻点，二阶判据在那里必然失效，必须单独处理。
2. 看到两条零集曲线一个相切（原点）、一个横截相交（另一点）→ 警觉：f 的符号由"点落在三条区域中的哪一条"决定；极值问题其实是"两条曲线的相对位置"问题，应该读符号分层而不是死算。
3. 看到 f 关于 y 是二次的（且 y² 系数为 1）→ 警觉：驻点方程 ∂f/∂y=0 可以**显式**解出 y 关于 x 的表达式，二维驻点系统可先降成一维，再解 ∂f/∂x=0；顺序错了会陷入两个非线性方程联立的泥潭。
4. 看到题面只说"求极值"、没给区域 → 警觉：需要在全平面找驻点并逐点判定；且"退化点没有极值"与"退化点无法用判据判断"是两件事，必须给出独立的符号论证。
5. 看到两个因子的零集在原点附近以**不同阶**（x² vs x³）消失 → 警觉：原点附近必须做尺度比较（谁大谁小取决于 x 的高阶项），线性化/二阶近似在那里不可信。

**predicted_first_transition**
- `before_state`: 全平面上的二变量极值问题；两个驻点方程耦合成二维非线性方程组，且其中一个驻点是退化的。
- `operation`: `RESTRICT_SLICE` —— 利用"f 关于 y 是二次的"这一题面可观察结构，把 ∂f/∂y=0 显式解成 y 关于 x 的依赖，将二维驻点搜索**限制到一条一维曲线**上。
- `after_state`: 驻点集合被参数化为一条一维曲线；剩下的 ∂f/∂x=0 变成单变量方程，驻点被逐个列出，极值判定成为对有限个点的分类问题。
- `why`: 题面可观察：f 是 y 的二次式且首项系数非零 → ∂f/∂y=0 一定可解出唯一的 y(x)；这是题面结构直接提供的降维。
- `basis`: from_problem_statement
- `trope_component`: medium（"令偏导为零"是常规动作，但"先降维再解"这一步是被二次结构逼出来的）

**predicted_second_transition**
- `before_state`: 有限个驻点；其中至少一个位于两条零集曲线的相切点，二阶判据在那里失效。
- `operation`: `CRITICAL_SCALE_PROBE` —— 在判据退化的驻点上放弃二阶信息，改为直接比较该点附近"y 相对 x²、x³ 的位置"（即读出三个符号区域），用尺度比较定出符号；其余驻点用常规二阶判据分类。
- `after_state`: 每个驻点都有确定的分类结论（真极值 / 非极值），退化点由符号分层论证收口，而不是由"判据失效"悬置。
- `why`: 题面可观察：两条零集曲线在原点相切 → Hessian 在该点退化是必然的（不是偶然），所以必须有替代论证；符号分层由两个因子在切点附近的相对阶直接给出。
- `basis`: from_problem_statement
- `trope_component`: medium-to-high（"退化点单独讨论 + 读符号"是标准套路，但相切结构是题面可观察的）

**prior_exposure_self_report**
moderate-to-strong。`f=(y-x²)(y-x³)` 这道 2023 年的题辨识度极高，我怀疑自己见过它（甚至对某个驻点处的极值数值有模糊印象）。**我在预测里刻意没有使用任何"答案级"记忆**（驻点坐标、极值数值、哪些点不是极值，全部没有写入本文件），只写了题面可观察的结构；但如果评分口径严格，请把本题视为可能被污染。

**uncertainty**
最没把握的是 **second_transition 是否覆盖了标准解真正的难点**：标准解也可能在列出驻点后，对退化点用的是"沿不同路径取极限得到不同符号"的论证，而不是我描述的"三层符号区域"读法——两者结构相近但措辞不同，可能被判 PARTIAL。第二没把握的是 T1：标准解可能直接联立求解而不强调"降维"这一步，那么 T1 会被看作机械步骤而非结构动作（SPEC §5 明确不把机械步骤升格为算子，如果 SCORER 这么判，T1 应记 MISS 而不是 PARTIAL）。

## M1-22-A-T17

**problem_geometry**
- `representation_issue`: 目标对象（曲线 y=y(x)）**没有显式给出**，只由微分方程 + 初值隐式定义；而要求的渐近线是该对象的"粗粒度"极限性质。目标与给定信息之间存在表示落差。
- `coupling`: y 与 y' 被方程系数耦合；系数在 x→0⁺ 处奇异（1/(2√x)→∞），与解在端点的行为耦合在一起。
- `scale_competition`: x→+∞ 时右端两项（常数项与 √x 项）不同阶，且积分因子 e^{√x} 与多项式增长不同阶 → 主导尺度需要判定；x→0⁺ 时系数发散是另一种尺度。
- `information_risk`: 初值提供的那个常数在 x→+∞ 时被指数因子压制（对斜渐近线**不可见**），在 x→0⁺ 时却保留（对端点行为**可见**）→ 同一份信息在两端的可见性不同；过早做主导平衡会丢掉决定截距的次阶项。
- `dependency_structure`: 解的显式表示依赖积分上限；两端极限必须从**同一个**表示中分别提取，先取哪端极限影响展开深度。
- `state_transition_structure`: 空。
- `resource_or_bottleneck_structure`: 空。

**main_obstacle**
问题结构是"**要一个隐式定义对象的极限性质**"：目标（渐近线）需要斜率**和**截距，而截距来自展开的**次阶项**——只做主导平衡只能得到斜率，得到的是不完整的渐近线；同时方程在定义域边界（x=0）处系数奇异，所以必须先在 (0,∞) 上把解表示成能同时读出两端行为的形式，再分别处理两端（一端主导尺度由指数因子决定、另一端由系数奇性决定）。难点是"目标要求次阶精度 + 信息在两端可见性不同"。

**trigger_candidates**
1. 看到目标不是 y(x) 本身，而是"曲线 y=y(x) 的渐近线" → 警觉：目标只是解的粗粒度极限性质，但**必须先有解的表示**才能谈；不能直接对解做数值或图形猜测。
2. 看到系数 `1/(2√x)` 恰好是 `√x` 的导数 → 警觉：左端在乘一个指数因子后就是一个**整体导数**，方程可一次性精确积分（无信息损失），不必用任何近似方法。
3. 看到方程含 `√x`（定义域只能是 x>0）而初值给在 x=1 → 警觉：解只在 (0,∞) 上有意义；渐近线要在 x→+∞ 与 x→0⁺ **两端**分别讨论，且 x=0 处系数奇异、必须确认解在那里是否有限。
4. 看到右端 `2+√x` 的两项在 x→∞ 时不同阶，且积分因子 e^{√x} 与多项式增长不同阶 → 警觉：只做主导平衡只能定出**斜率**，**截距**来自次阶项；展开深度不够就拿不到完整的渐近线。
5. 看到初值只贡献一个可加常数 → 警觉：该常数在 x→∞ 时被指数因子压制（对斜渐近线不可见），在 x→0⁺ 时保留（对端点行为可见）；不能想当然认为初值对所有目标都重要，也不能认为它都不重要。

**predicted_first_transition**
- `before_state`: 一个由一阶线性方程 + 初值隐式定义的函数；目标是它的渐近线，但解没有可读的显式表示。
- `operation`: `STATE_REREPRESENTATION` —— 识别系数是某个简单函数的导数（题面可观察），据此把方程左端改写成一个**整体导数**（等价于换一个依赖变量），从而一次性精确积分，得到含积分上限的表示。
- `after_state`: y 被表示为"指数因子 ×（初值常数 + 一个变限积分）"；两端极限都从这一个表示中读出，不再需要任何近似。
- `why`: 题面可观察：系数 `1/(2√x)` 与 `√x` 的导数完全相同 → 左端是乘积导数展开式的一项；这是题面直接给的结构，不是套路选择。
- `basis`: from_problem_statement
- `trope_component`: medium-to-high（"一阶线性方程 → 积分因子"是教科书套路，但这里系数恰是简单函数的导数是题面可观察的；我的标签选择可能受套路影响）
- *备选标签*：`EXACT_ELIMINATION`（"把两项合并成一个精确导数"）——同样是词表无定义导致的歧义。

**predicted_second_transition**
- `before_state`: 解已有一个含变限积分的表示；但目标是渐近线，需要斜率**与截距**。
- `operation`: `REPAIR_SCALE_MATCHING` —— 对表示做渐近展开时，保留到**足以定出截距的次阶**（而不是只做主导平衡），在 x→+∞ 端提取完整的一次渐近；同时在 x→0⁺ 端判定积分是否收敛（决定有无竖直渐近线）。
- `after_state`: 得到完整的斜渐近线（斜率 + 截距），并确认另一端是否有竖直渐近线；两端结论都落到同一个表示上。
- `why`: 题面可观察：右端与积分因子的阶差决定了"斜率来自主导项、截距来自次阶项"；而 x=0 处系数奇异迫使另一端必须单独判定。
- `basis`: from_problem_statement
- `trope_component`: **high**（"求渐近线 → 展开到次阶取截距"是标准套路；题面只提示了目标，没有区分性特征。按口径 2，这条建议计入 pattern_recall）
- *备选标签*：`CRITICAL_SCALE_PROBE`（若把重点读成"判定主导尺度"）。

**prior_exposure_self_report**
weak-to-moderate。2022 年这道"解微分方程后求渐近线"的题我印象不深；但"线性方程 → 积分因子 → 求渐近线"这一整套流程是高度模板化的。

**uncertainty**
最没把握的是 **second_transition 的完整度**：标准解可能只求 x→+∞ 端的斜渐近线、不讨论 x→0⁺ 端（若如此，我 T2 里"两端分别判定"的部分会多出一块标准解没有的动作，可能被判 PARTIAL 或 FALSE_TRIGGER）。第二没把握的是：标准解是否真的需要次阶展开才能得到截距——如果截距恰好能从某个极限直接读出，那我的"保留次阶"描述就过强了。

## M1-21-A-T18

**problem_geometry**
- `representation_issue`: 通项是**两种不同 n-依赖机制之和**（对 n 呈几何型的一项，与对 n 呈幂型并带有理权重的一项）；级数既不是幂级数也不是几何级数，通项的 x-依赖不是单一类型 → 单一收敛判据不适用。
- `coupling`: 两种机制在同一通项里相加；整体收敛性由较弱的一方决定，而"和函数"必须分别在各自的有效域上求和，不能对整个通项一次性处理。
- `scale_competition`: 两种机制的收敛边界**不是同一条**（一个的边界由 x=0 决定，另一个由 |x|=1 决定）→ 收敛域的端点是两个机制竞争的产物。
- `information_risk`: 先拆分再取并/交而不检查**边界点**，会丢掉边界点上的收敛/发散信息；且和函数的闭式在部分区域外无定义（对数型只在 |x|<1 内为实）→ 不能在整域上用同一个公式。
- `dependency_structure`: 收敛域的确定先于和函数；和函数可能按域分段，边界点必须单独判。

**main_obstacle**
问题结构是"**一个通项里装了两种收敛机制，且两者的收敛边界不同**"：域必须按机制分别判定后取交，而交的端点恰好落在两个机制各自的临界点上，端点必须逐个单独判定；进一步，"和函数"不是整个域上的单一闭式（其中一块的闭式只在一个子区域内有效），所以和函数必须与域的分段结构配套给出。难点是"多重机制的边界竞争 + 闭式有效域小于收敛域"。

**trigger_candidates**
1. 看到通项是 `e^{-nx}` 与 `x^{n+1}/(n(n+1))` 两项之和 → 警觉：这是两种不同的 n-依赖机制（几何型 vs 幂型带有理权重），级数不是单一类型；收敛域必须按机制**分别**判定再取交，不能整体套一个判据。
2. 看到第一项含 `e^{-nx}`（对 x 是指数依赖、对 n 是几何型）→ 警觉：它的收敛边界由 **x=0** 决定，而不是由 |x|=1 决定 → 与第二项的边界不是同一条，域的形状由两条边界的交决定。
3. 看到第二项的权重 `1/(n(n+1))` → 警觉：这个权重可裂成两项之差（望远镜型/积分型），和函数的闭式会是**对数型**，只在 |x|<1 内有效；边界 x=1 必须单独判定。
4. 看到题面同时要求"收敛域**及**和函数"（两个目标）→ 警觉：域要先定，且和函数可能**分段**（内部闭式与边界点取值不同），不要用一个公式覆盖全域。
5. 看到 x 可以取负（`x^{n+1}` 带符号）→ 警觉：必须检查 x<0 时第一项（`e^{-nx}` 随 n 指数增长）是否使通项不趋于零 → 域可能被负侧直接截断，负侧不需要精细判据。

**predicted_first_transition**
- `before_state`: 一个通项由两种机制相加而成的级数；收敛域与和函数都无法用单一判据/单一闭式处理。
- `operation`: `INVARIANT_BLOCK_DECOMPOSITION` —— 按 n-依赖机制把级数拆成两个互不混合的块，每块各自是可识别的标准型，各自有自己的收敛边界。
- `after_state`: 问题变成"两个独立块各自的收敛域 + 各自的和函数"；整体域的确定成为两个域的集合运算。
- `why`: 题面可观察：通项是两个结构不同的项之和，级数对加法可拆；两块之间没有相互依赖 → 拆分是题面结构直接允许的。
- `basis`: from_problem_statement
- `trope_component`: medium（"求和项级数先拆"是常规动作，但"两块边界不同"是题面可观察的）
- *备选标签*：`INFORMATION_AXIS_DECOMPOSITION`（"两条独立的收敛轴"）——词表无定义导致的歧义。

**predicted_second_transition**
- `before_state`: 两个独立块各自的收敛域；但两块边界的端点（x=0 与 |x|=1）落在不同位置，整体域的端点需要单独判定。
- `operation`: `CRITICAL_SCALE_PROBE` —— 分别探两个块在各自临界点上的行为（几何型块在 x=0 处通项不趋于零 → 发散；幂型块在 |x|=1 的两个端点上需分别判定），据此定出整体收敛域及其端点。
- `after_state`: 收敛域（含端点归属）被完全确定，且已识别出"域内某一侧被一个机制截断"这一事实。
- `why`: 题面可观察：两块边界位置不同（一个由 x=0、一个由 |x|=1 决定）→ 端点是两个机制竞争的产物，必须逐个探。
- `basis`: from_problem_statement
- `trope_component`: medium-to-high（"级数收敛域要单独查端点"是标准套路，但这里两个机制的边界不同是题面可观察的）

## M1-24-A-T21

**problem_geometry**
- `representation_issue`: 三个标量递推 vs. 一次线性映射的迭代；题面已指定用 α_n = Aα_{n-1} 的表示，但"第 n 次迭代"在原始坐标下没有可计算的表达 → 必须换到使映射作用简单的坐标。
- `coupling`: x_n 依赖 x_{n-1} 与 z_{n-1}；y_n 依赖 y_{n-1} 与 z_{n-1}；z_n 依赖三者 → **z 是耦合枢纽，x 与 y 之间没有直接耦合**（星形/三角耦合图），存在层次。
- `dependency_structure`: α_n 完全由 α_0 与 A 决定，各分量按同一步演化，迭代序固定。
- `information_risk`: 若 A 有非零核方向，初值在该方向上的分量**迭代一步后即被抹掉**，关于 α_0 的信息不可逆丢失。**题面可观察**：系数矩阵第三行恰好是前两行的线性组合（逐项可核对）→ A 奇异 → 必存在非零核方向。
- `state_transition_structure`: 本质是"状态 α + 一步转移 A"的**离散线性动力系统**，目标是第 n 步状态。

**main_obstacle**
问题结构是"**求一个线性映射的第 n 次幂（等价于耦合线性递推的通项）**"：直接迭代是 O(n) 且没有闭式，耦合使三个序列不能分别求通项；必须换到映射作用为标量（对角）的坐标。同时题面可观察地暴露了 A 的**行相关性**，这意味着 A 奇异、存在被抹掉的方向——通项实际上只依赖初值在"存活方向"上的投影，若在原始坐标下展开初值会白算被抹掉的分量。难点是"迭代型目标 + 谱结构未知（是否可对角化）+ 存在信息不可逆丢失的方向"。

**trigger_candidates**
1. 看到题面直接给出 α_n = Aα_{n-1} 并要求 A^n 与三个数列的通项 → 警觉：目标是"线性映射的第 n 次幂"，原始坐标下迭代不可行；必须换到使映射作用对角/分块的坐标。
2. 看到系数矩阵的第三行**恰好是前两行的线性组合**（可逐项核对：第三行 = 3×第一行 + 1.5×第二行）→ 警觉：A 奇异、有非零核方向；该方向上的初值分量迭代一步后消失（信息不可逆丢失），且 A^n 对 n≥1 必然降秩。这是题面里可以直接看出来的，不需要先算特征值。
3. 看到 x_n 与 y_n 的方程中**不出现对方**（只通过 z 耦合）→ 警觉：耦合图是星形/三角结构，存在层次，可能有可分解的不变子空间，不要一上来就当满耦合矩阵硬算。
4. 看到初值 α_0 是给定的三数组、而目标是三个数列的通项 → 警觉：通项只依赖 α_0 在**存活方向**上的投影；应先确定谱结构再展开 α_0，否则会白算被抹掉的分量。
5. 看到 3×3 整数矩阵、题目分值高 → 警觉：需要判断是否可对角化（谱是否有重根），不能默认一定可对角化；若有重根还要处理 Jordan 块。

**predicted_first_transition**
- `before_state`: 三个耦合的标量线性递推；目标是 A^n 与三个通项，原始坐标下无闭式。
- `operation`: `INVARIANT_BLOCK_DECOMPOSITION` —— 求出 A 的谱（特征多项式）并把空间分解成不变子空间，使 A 在这些坐标下变成标量/分块对角作用。
- `after_state`: 问题变成"在各不变子空间上取第 n 次幂（标量幂 λ^n）"；A^n 与通项都归结为坐标变换 + 标量幂 + 变换回原坐标。
- `why`: 题面可观察：目标是线性映射的第 n 次幂；而题面同时暴露了行相关（奇异）与星形耦合图 → 提示矩阵有非平凡谱结构。**但"选对角化而不是试算 A²、A³ 找规律"这个选择本身，主要来自教科书惯例。**
- `basis`: **pattern_recall** —— 题面并没有排除"计算 A²、A³ 找规律"或"Cayley–Hamilton 降幂"等替代路线；我选择"换到特征坐标"是因为这是"求 A^n"的标准套路，加上我对 2024 年这道题的模糊熟悉感。如实标注。
- `trope_component`: high
- *说明*：我把这一条标成 pattern_recall，是因为按任务书的口径，**"求 A^n → 对角化"属于"这种题一般怎么做"的记忆套路，而题面里没有能把它与替代路线区分开的特征**。宁可多标，不隐瞒。

**predicted_second_transition**
- `before_state`: 空间已分解成不变子空间；但题面可观察的行相关意味着至少一个子空间是核（特征值 0）。
- `operation`: `QUOTIENT_KERNEL` —— 把核方向从状态中商掉：该方向上的初值分量在一步之后不再携带任何信息，通项只依赖 α_0 在存活子空间上的投影；据此只对存活方向展开初值。
- `after_state`: 通项的表达式只含存活方向的标量幂与 α_0 的投影；被抹掉的分量显式地被排除，计算量下降。
- `why`: 题面可观察：第三行是前两行的线性组合 → 行列式为 0 → 存在非零核方向；核方向上的分量不可能在第 n 步状态里出现（这正是"信息不可逆丢失"）。
- `basis`: from_problem_statement
- `trope_component`: medium（"零特征值方向对 n≥1 无贡献"是常规结论，但核的存在性是题面可观察的）

**prior_exposure_self_report**
moderate。2024 年这道"三数列 + 矩阵 + A^n"的线代题辨识度较高，我对它的谱结构有模糊印象（因此我在本文件中**刻意没有写出任何特征值或 A^n 的具体结果**）。**本题的 T1 我已自行标为 pattern_recall；若评分口径严格，请把本题整体按污染处理。**

**uncertainty**
最没把握的是 **second_transition 是否是标准解的一个独立步骤**：标准解可能把"核方向消失"和"坐标变换"合并在一步里完成（那样 T2 会被判 PARTIAL 而不是 HIT）。第二没把握的是 T1 的标签：`INVARIANT_BLOCK_DECOMPOSITION` 与 `STATE_REREPRESENTATION`（换基）之间我无法在无定义情况下区分；如果标准解被标成后者，我这条会因命名而不命中。

## M1-23-A-T22

**problem_geometry**
- `representation_issue`: 联合密度只通过 `x²+y²` 依赖变量，支撑是**圆盘**；直角坐标下看不出径向结构，而三个目标（协方差、独立性、Z=X²+Y² 的密度）都指向径向/角向的分解。
- `coupling`: X 与 Y 通过联合密度与圆盘支撑耦合；"是否独立"这一问正是问这种耦合能否因子化。
- `redundant_freedom`: 存在一个**不改变密度、也不改变 Z 的对称方向**（角向）；该方向对目标 (1)(3) 不可见，但对 X、Y 各自的边缘分布是可见的（这是"看起来对称"与"独立"之间陷阱的来源）。
- `information_risk`: 只用边缘密度无法回答独立性（联合信息已被积分掉）；支撑不是乘积集 → "密度只依赖 r" 会被误读成独立（错误方向）；反之若为了判独立而保留整个二维积分又代价过高。
- `dependency_structure`: (1)(2) 依赖二维积分与边缘化；(3) 依赖从二维密度到一维密度的**降维**（沿 Z 的水平集积分）；三问共享同一坐标结构。

**main_obstacle**
问题结构是"**目标量在一个对称方向上要么不可见、要么被精确抵消，但支撑不是乘积集**"：密度是径向的、区域是圆盘，所以最自然的坐标是径向/角向；在那种坐标下，(1) 的交叉项会被对称性精确消去（不需要数值积分），(3) 的降维变成沿角向积分掉一个不可见方向；但正因为支撑是圆盘而不是矩形，径向对称**不蕴含** X 与 Y 独立——"看起来对称所以独立"是本题结构里最强的错误吸引子。

**trigger_candidates**
1. 看到密度只通过 `x²+y²` 依赖变量、支撑是圆盘 `x²+y²≤1` → 警觉：存在旋转对称；自然坐标是径向/角向，直角坐标下三个目标都要硬算二维积分。
2. 看到支撑是**圆盘**而不是矩形（不是乘积集）→ 警觉：X 与 Y 的独立性几乎必然不成立——边缘支撑的乘积（正方形）严格大于联合支撑；**不要因为"密度只依赖 r"就误判独立**。
3. 看到目标 (3) 是 `Z = X²+Y²`（正是径向坐标的平方）→ 警觉：Z 对**角向完全不可见** → 应把角向自由度积分掉（沿 Z 的水平集/等值线积分），而不是对二维密度直接做变量替换硬算 Jacobian。
4. 看到被积函数对 x、y 是奇/偶的对称组合、区域关于原点对称 → 警觉：交叉矩的角向积分可能被对称性**精确**消去，不必数值估计——但必须把对称性论证写出来（"精确消去"与"近似忽略"是两件事）。
5. 看到三个小问共用同一个密度 → 警觉：三问共享同一结构（径向/角向分解），应一次建立坐标再分别回答，而不是每问各做一次二维积分（重复计算 + 结论不互洽）。
6. 看到密度在圆盘中心取零、在边界最大 → 警觉：质量集中在边界附近；任何"均匀近似"都会破坏正确答案的结构。

**predicted_first_transition**
- `before_state`: 一个支撑为圆盘、只依赖 x²+y² 的二维密度；三个目标在直角坐标下都要做二维积分，且看不出 (1)(3) 之间的共同结构。
- `operation`: `STATE_REREPRESENTATION` —— 换到与对称性匹配的径向/角向坐标，使圆盘支撑变成矩形、密度只依赖径向变量，并把面积元的 Jacobian 显式带入。
- `after_state`: 问题变成"径向部分 + 角向部分"的乘积形式；区域边界消失（矩形），角向积分可独立完成。
- `why`: 题面可观察：密度是 `x²+y²` 的函数、支撑是圆盘 → 两个可观察特征同时指向同一个坐标变换。
- `basis`: from_problem_statement
- `trope_component`: medium-to-high（"圆盘 → 极坐标"是教科书套路，但题面的径向结构确实是区分性特征）
- *词表缺口*：这个动作的本质是"换到**对称适配**坐标"，现有标签里没有对应格位，只能塞进 `STATE_REREPRESENTATION`。

**predicted_second_transition**
- `before_state`: 径向/角向分离的形式；角向方向对 (1)(3) 的目标量不可见。
- `operation`: `QUOTIENT_KERNEL` —— 把"目标量看不见的角向方向"商掉：对 (3) 是沿 Z 的水平集把角向自由度积分掉（二维密度降成一维）；对 (1) 是利用同一对称性使交叉矩的角向积分**精确**为零。
- `after_state`: (1)(3) 都退化为一维径向积分/一维分布问题；只有 (2) 仍需要联合与边缘的直接比较。
- `why`: 题面可观察：Z=X²+Y² 与径向密度的径向部分都与角向无关（旋转对称）→ 角向是可商掉的不可见方向。
- `basis`: from_problem_statement
- `trope_component`: medium（"利用对称性消去/积分掉一个方向"是被题面结构逼出来的）

**prior_exposure_self_report**
strong。`f(x,y) = (2/π)(x²+y²)` 在单位圆盘上这道 2023 年的题辨识度非常高，我**很可能见过它的标准解**（我对"协方差为零、不独立、Z 的密度"这三问的走向有印象）。我在本文件中刻意没有写任何结果数值（协方差值、边缘密度、Z 的密度表达式）。**如果评分口径严格，请把本题整体按 pattern_recall 处理——我自己已经认为它的预测价值是可疑的。**

**uncertainty**
最没把握的是 **second_transition 覆盖不全**：本题第 (2) 问（独立性）的结构动作与 (1)(3) 不同——它是一个**否定性判定**（比较联合支撑与边缘支撑的乘积），我把它放进了 trigger 而没有放进两条 transition。如果标准解把 (2) 当作承重步骤，我的 T2 会显得偏了方向。第二没把握的是 T1 的标签归属（`STATE_REREPRESENTATION` vs 一个词表里不存在的"对称适配坐标"算子），这会导致纯命名层面的不命中。
