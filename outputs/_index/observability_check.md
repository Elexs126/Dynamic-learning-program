# trigger_signals 可观察性核验（符号级）

任务书 §18 要求攻击"trigger 是否真的从题面可观察"。
本检查只做**低误报**的那一部分：trigger 引用的数学符号若在题面中不存在，
值得人工看一眼。

## ⚠️ 这是**分诊清单，不是判决**

**触发信号是诊断，不是引文。** 它天然会引入题面里没有的符号，例如：
- 求解者**自己定义**的辅助对象（令 `F = f·f'`，`F` 当然不在题面里）；
- 求解者**引入的已知关系**（`1-cos x ~ x²/2` 里的 `~`，题面不会写）；
- 求解者**命名的新量**（把某个极限记作 `A`）。

以上三类都**完全合法**。本检查把这类一并标出，是因为机器无法区分
"合法引入的新符号"与"从答案反推才出现的符号"。
**因此 `SYMBOL_MISSING` 只表示"值得 Critic 复核"，不表示该 trigger 有问题。**
真正需要警惕的信号是：trigger 引用了**题面中完全不存在、且求解者也没有理由引入**的对象。

- 核验 trigger 条数：**1019**
- OK：201
- SYMBOL_MISSING：198
- NO_SYMBOLS：620

> `NO_SYMBOLS` = 该 trigger 不含可检测的数学符号，本检查不适用（既不算通过也不算失败）。
> 它占比最高（约一半）是正常的——多数 trigger 是结构性描述（"分子分母同次齐次"），本来就不含符号。
