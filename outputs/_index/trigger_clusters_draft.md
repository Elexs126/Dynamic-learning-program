## ⚠️ 负结果：词面聚类失败了

用字符 3-gram Jaccard（阈值 0.34）对 **484** 条 trigger 信号做贪心聚类：
得到 **482 组，其中 480 个是单例**。

原因：这些信号**结构相近但用词极不相同**。例如下面两条是同一个结构动作，字面重合却极低：

- `"待证式可整理为 f'+φ'f=0 的形状 → 这是乘积求导公式逆用的指纹 → 提示存在 F(x)=f(x)e^{φ(x)}"`
- `"(II) 目标 f''+f'=1 形如 g'+g=0 → 见到 f'+f 型 → 乘 e^x"`

**所以 trigger 聚类没有任何词面捷径，必须靠语义。** 这同时是一个**正面**证据：
trigger 的表面形式足够多样，说明抽取者没有套模板。

（这与 `family_seeds.json` 的教训一致：机械签名曾把 91 条切成 51 个桶、36 个是单例。）

- `M1-012`（M1, 高等数学）出现 $x^3$ 项 → 提示需要检查有几条路径能贡献到 $x^3$
- `M8-012`（M8, 概率论与数理统计）联合密度是指数上的二次型，含交叉项 → 配方可以把耦合从「形状」移到「位置」，从而把二维积分拆成一维积分
- `M8-012`（M8, 概率论与数理统计）题目同时要求 A 与条件密度 f_{Y|X}，而 f_{Y|X} 的分母正是 f_X → 两个目标共用同一个一维积分，提示先求 f_X 一举两得

### `RIGIDIFY`（4 条，高等数学）

- `M1-021`（M1, 高等数学）只给出 f' 的区间估计而没有 f 的表达式 → 提示唯一可用的桥梁是中值定理，且信息形式是「压缩」
- `M1-021`（M1, 高等数学）$0<f'<1/2$ 中的常数 1/2 严格小于 1 → 提示相邻项之差按几何级数衰减，级数绝对收敛
- `M1-021`（M1, 高等数学）第 (I) 问是「级数 $\sum(x_{n+1}-x_n)$ 绝对收敛」而不是「数列收敛」→ 提示先做差分压缩，再由部分和得到数列收敛
- `M1-021`（M1, 高等数学）结论要求 $0<\lim x_n<2$ 这一开区间 → 提示需要用递推等式本身（配合 $f(0)=1$）来定界，而不是靠数值估计

### `NORMALIZE`（3 条，高等数学）

- `M1-008`（M1, 高等数学）自变量趋 1 而不是 0，但表达式里全是 ln 形式 → 提示必须先把 1 平移成 0（用 $\ln x = \ln(1+(x-1))$）才能用等价无穷小
- `M1-008`（M1, 高等数学）出现 $\ln x$ 与 $\ln(1-x)$ 的乘积，且两者分别趋 0 与 $\infty$ → 0·∞ 型
