## 4. 基础篇 vs 强化篇 阶段版本对照（核心增值点）

> 按要求，**同一问题结构在两篇各出现一次时各写一条独立 Episode，未合并**。
> 下列对照只陈述事实差异，是否构成「不同章节出现相同问题结构」的证据由聚合 worker 判定。

### 对照 A：`AB=O` + 方阵 + 参数 → 求参数

| | 基础篇 M7-004（第04章 例3） | 强化篇 M7-008（第01章 例1.20） |
|---|---|---|
| 题干 | $A=\begin{bmatrix}1&2&-2\\4&t&3\\3&-1&1\end{bmatrix}$，$B\neq O$，$AB=O$，求 $t$ | $A=\begin{bmatrix}1&a&0\\a&1&1\\1&1&-1\end{bmatrix}$，$B\neq O$，$AB=0$，求 $a$ |
| 第一步 | 按列分块（两篇相同） | 按列分块（两篇相同） |
| 第二步 | 显式展开：$B\neq O\Rightarrow\exists\beta_i\neq0\Rightarrow Ax=0$ 有非零解 $\Rightarrow r(A)<3$ | 跳过秩的语言，直接写「由克拉默法则，有 $\lvert A\rvert=0$」 |
| 等价链长度 | 4 步（列分块 → 非零解 → 秩亏 → 行列式） | 2 步（列分块 → 克拉默法则逆否 → 行列式） |
| 是否检验二次方程的根 | 未展开讨论 | 未展开讨论（两篇都停在「$a=1$ 或 $-2$」） |

**发现**：同一结构在两篇的**唯一差异是等价链的长度**。基础篇把「秩」这一中间语言写出来，强化篇把它压缩掉。
这提示「熟练度」在本项目里可以被刻画为**等价链的压缩程度**，而压缩掉的中间语言正是基础阶段需要显式持有的东西。
另：两篇都**没有**检查「$a=1$ 与 $a=-2$ 是否都真能支撑非零 $B$」——这是一个两篇共有的未闭合点（M7-008 的 `naive_routes` 已记录为 `TARGET_DRIFT`）。

### 对照 B：交错的二次矩阵方程 → 求 $X$

| | 基础篇 M7-002（第02章 例11） | 强化篇 M7-011（第02章 例2.31） |
|---|---|---|
| 方程 | $AXA+BXB-AXB-BXA=E$ | $AXA-BXB=BXA-AXB+E$ |
| 四项系数模式 | $++,+-, -+, --$ | 移项后 $++,+-,--,-+$ |
| 配成的形式 | $(A-B)X(A-B)=E$（**左右因子相同**） | $(A-B)X(A+B)=E$（**左右因子不同**） |
| 答案 | $X=[(A-B)^{-1}]^2$（同一个逆的平方） | $X=(A-B)^{-1}(A+B)^{-1}$ |
| 考查形式 | 直接求 $X$ | **四选一**，选项 (A) $(A^2-B^2)^{-1}$、(C) $(A+B)^{-1}(A-B)$ 都是「交换律/顺序」陷阱 |
| 讲义是否给出思路文字 | 只有计算步骤（故本条 E1） | `【分析】` 只有「据已知，有」四字（故本条也是 E1） |

**发现**：这是同一「交错二次式」结构在**不同符号排列**下的两个版本，而符号排列直接决定了左右因子是否相同、答案形式是否成立。
强化篇把这个差异**做成了选项陷阱**（(A) 与 (C) 分别对应「默认交换律」与「顺序颠倒」两种错误），
说明强化阶段考查的正是「矩阵乘法不可交换」这一约束在结构识别中的位置。
两篇的 `【分析】` 都**没有**叙述因式分解的思路——这是两篇共同的信息缺口（因此两条都只能标 E1）。

### 对照 C：用 $A$ 作坐标变换消掉逆矩阵

| | 基础篇 M7-007（第06章 例17：$A^{*}$ 正定） | 强化篇 M7-019（第06章 例6.18：$A^{-1}$ 正定） |
|---|---|---|
| 目标对象 | $A^{*}=\lvert A\rvert A^{-1}$（多一个正系数 $\lvert A\rvert$） | $A^{-1}$（纯逆） |
| 路线数 | 2 条：定义（$x=Ay$）+ 特征值 | 3 条：特征值 + **与 $E$ 合同** + 定义（$x=Ay$） |
| 核心一步 | $x^{T}A^{*}x=(Ay)^{T}\lvert A\rvert A^{-1}(Ay)=\lvert A\rvert\,y^{T}Ay$ | $x^{T}A^{-1}x=(Ay)^{T}A^{-1}(Ay)=y^{T}Ay$ |
| 多出的难点 | 需额外说明 $\lvert A\rvert>0$ 保号 | 需额外走一遍合同路线：对 $C^{T}AC=E$ 取逆 |
| 讲义原话形式 | `方法一用定义.因A可逆，故 $x = A y$ 是坐标变换…` | `（方法三）（用定义，坐标变换）因为A正定，那么A可逆，对二次型…作坐标变换 $x = A y$` |

**发现**：两篇共享同一核心动作（**用 $A$ 作坐标变换把逆抵消**），但**强化篇显式增加了「与 $E$ 合同」这条路线**，
且把「正定性有三种等价刻画」这一事实变成了可选择的路线集。基础篇只给两条，强化篇给三条——
这与对照 A 的结论方向相反：A 是「压缩等价链」，C 是「扩张路线集」。
两条一起看，强化阶段的变化不是单向的简化，而是**同时压缩执行链、扩张可用策略集**。
