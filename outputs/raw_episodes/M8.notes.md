## 0. 关于本材料的一条重要事实：概率讲义的推理层薄，且用的是另一套标记

这一点直接决定了我全部的证据分级，必须写在最前面。

**事实：**

| 标记 | 高数/线代讲义 | 概率讲义 |
|---|---|---|
| `分析` | 有（全库 774 处） | **0 处** |
| `方法总结` | 有（全库 77 处） | **0 处** |
| `良哥解读` | 无 | **144 处**（概率讲义独有） |
| `考点及方法小结` | 无 | **16 处**（概率讲义独有） |
| `方法` / `注意` / `技巧` / `注` | 部分 | 30 / 3 / 2 / 9 处 |

概率讲义的推理层不是缺失，而是**换了标记名**：`良哥解读`（基础篇）+ `考点及方法小结`（强化篇）。这两者是我 `evidence_excerpt` 的首选来源。

**但是**：`良哥解读` 的分布极不均匀。基础篇 ch03 有 18 处，而强化篇 ch07（参数估计）**一处都没有**、强化篇 ch05（大数定律）**一处都没有**、强化篇 ch01 只有 4 处。也就是说，**参数估计、极限定理、事件概率这三块的例题几乎只有「解析」而没有「方法评述」**。

**后果（如实报告）：**

- 我的 24 条中 **E1 = 13 条（54%）、E2 = 11 条（46%）、E0 = 0 条**。
- 这与材料属性一致：**E1 比例跟随材料推理标记密度，而不是 worker 的勤勉程度**。凡是 `良哥解读`/`考点及方法小结` 有对应原话的题（主要是 ch03 多维随机变量、ch04 数字特征），我都标了 E2；凡是只有解析的题（主要是 ch01、ch05、ch07），我**如实标 E1，没有为了好看抬成 E2**。
- 我另在 11 条 Episode 的 `notes` 里显式登记了 `UNKNOWN 子步骤`——即该条中**某一个子步骤**无法由题面结构或讲义原话自然解释，并把 `confidence` 降为 `medium`。这些子步骤是本 worker 认为最有价值的「疑似缺失概念」线索，清单见 §4。

**⚠️ 关于 `【题型N】` 标题：** 概率讲义用 `【题型一二维离散型随机变量及其分布】` 这类标题组织内容（强化篇 24 处）。按 SPEC 禁止 2，**我完全没有用题型分类作为组织方式**——本文件所有 Episode 的组织轴是「问题结构 → 障碍 → 变形」，题型名只作为 `notes` 里的检索辅助标签出现。

## 6. 基础篇 ↔ 强化篇 同结构对照（本 worker 的核心发现）

按任务书要求，**同一问题结构在两篇各出现一次时各写一条独立 Episode，不合并**。以下是我识别出的对照关系。**注意：我只做「识别与登记」，不做 E4 判定（SPEC §5：E3+ 由后续聚合 worker 判定）。**

### 对照 1（最强，两侧均已立条）：支撑集依赖参数的 MLE

| 维度 | 基础篇 ch07 → **M8-007** | 强化篇 ch07 例7.6 → **M8-021** |
|---|---|---|
| 密度 | `f(x;θ)=2e^{-2(x-θ)}, x≥θ` | `f(x;θ)=1/θ, 0≤x≤θ` |
| 参数身份 | 支撑集**下界** + 强度参数 | 支撑集**上界** + 尺度参数 |
| 导数符号 | `dlnL/dθ = 2n > 0`（恒正） | `dlnL/dθ = -n/θ < 0`（恒负） |
| 可行域 | `θ ≤ min(x_i)` | `θ ≥ max(x_i)` |
| 估计量 | `θ̂ = min{x_i}` | `θ̂ = max{X_i}` |
| 额外要求 | 无 | 额外要求导出 `[F(x)]^n` 并讨论**有偏性**（`E(θ̂)=nθ/(n+1)`） |

**结构同一性**：参数出现在支撑集边界 → 驻点法失效（导数恒正/恒负）→ 最值落在数据决定的边界 → 估计量是**次序统计量**。
**两篇差异**：基础篇只到「取 min」为止；强化篇把「min/max 型估计量的分布 `[F]^n`」和「无偏性讨论」补上，并把同一结构在例7.11 里第三次使用（`T_c=c·X_(n)` 求无偏 c 与最小 MSE 的 c）。**这是 E4 候选，也是 `CANDIDATE_SUPPORT_BOUNDARY_ARGMAX` 的核心证据簇。**

### 对照 2（仅强化侧立条，基础侧缺）：条件分布 × 边缘分布 → 联合分布

| 维度 | 基础篇 ch03（未立条） | 强化篇 ch03 例3.7 → **M8-011** |
|---|---|---|
| 结构 | X~P(λ) 上客人数，Y\|X=n~B(n,p) 下车人数 | N~P(8) 损失事件次数，M\|N=n~B(n,p) 理赔次数 |
| 要求 | 只要求写出**联合分布** `P{X=n,Y=m}=P{Y=m\|X=n}P{X=n}` | 要求把 N **求和消去**得到 M 的边缘分布（`M~P(2)`） |
| 难度 | 低（一步乘法） | 高（需要 `C_n^m/n!` 约化 + `∑6^k/k!=e^6` 收口 + n=0/n≥1 分支） |

**结构同一性**：两阶段实验，「条件分布 × 边缘 = 联合」。
**两篇差异**：强化篇多一步**边缘化**。基础篇那条结构太薄（一步乘法），按 SPEC §4「宁少勿滥」我未立条，只在 M8-011 的 notes 中登记。**这是本 worker 的一处对照缺口**，若需要补基础侧，材料位置为 `01_基础篇/第03章_多维随机变量及其分布.md` L257–285。

### 对照 3（仅强化侧立条）：离散 + 连续混合的函数分布

| 维度 | 基础篇 ch03 第九节（未立条） | 强化篇 ch03 例3.29 → **M8-013** | 强化篇 ch02 例2.30（未立条） |
|---|---|---|---|
| 分区变量来源 | 题面**直接给出**离散 X（取值 1,2） | 由**连续变量取整**派生（`Z=[X]`） | 题面直接给出离散 X（取值 1,2） |
| 目标 | U=X+Y 的**密度** | Y=[X]+X 的**密度** | Y 的**分布函数** |
| 结构 | 按 X 取值分区 + 全概率 + 加权 | 同上，且分区同时消解了取整函数的不连续性 | 同上 |

**结构同一性**：按离散变量分区 + 全概率 + 分支加权。
**两篇差异**：强化篇的分区变量可以由**连续变量派生**（取整），这是一个额外结构；基础篇的分区变量是题面给定的。→ 属 `CANDIDATE_CONDITIONAL_MIXTURE_EMBEDDING` 的派生情形。

### 对照 4（仅基础侧立条）：二维正态 + ρ=0 ⇒ 独立，再按符号分区

| 维度 | 基础篇 ch03 → **M8-002** | 强化篇 ch03 例3.15（未立条） | 强化篇 ch03 例3.16（未立条） |
|---|---|---|---|
| 题 | (X,Y)~N(0,0;1,1;0)，P{X/Y<0} | (X,Y)~N(1,0;1,1;0)，P{XY-Y<0} | (X,Y)~N(0,0;1,4;-1/2)，找与 X 独立的标准正态线性组合 |
| 关键步 | 商<0 ⇔ 异号 ⇒ 象限分区 | **先因式分解** `XY-Y=(X-1)Y` 再分区 | 用「二维正态 + 协方差为 0 ⇒ 独立」把独立判定降级为协方差计算 |

**结构同一性**：`ρ=0`（或协方差为 0）在二维正态下升级为独立 ⇒ 可拆乘积；符号型事件按象限分区。
**两篇差异**：强化篇增加「先因式分解再分区」与「把独立判定降级为协方差计算」两个变体。→ 属 `CANDIDATE_SIGN_PARTITION` 的证据簇。
