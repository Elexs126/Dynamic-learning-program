# 408 计算机学科专业基础综合历年真题集（2009 - 2026）

本目录收录了 2009 年至 2026 年（共 18 年，846 道题目）全国硕士研究生招生考试**408计算机学科专业基础综合**完整真题集。

## 试卷科目构成

- **数据结构**（45 分）：线性表、栈和队列、树与二叉树、图、查找、排序、算法设计
- **计算机组成原理**（45 分）：数制与编码、定点/浮点运算、存储系统、指令系统、CPU控制单元、流水线、总线与I/O
- **操作系统**（35 分）：进程管理与同步、内存管理、文件系统、I/O设备管理
- **计算机网络**（25 分）：物理层、数据链路层、网络层与路由、传输层TCP/UDP、应用层协议

## 题目标签说明

每道题目后均附有标准属性标签与可折叠参考答案解析：
- **【题型】**：选择题 / 综合应用题
- **【科目】**：数据结构 / 计算机组成原理 / 操作系统 / 计算机网络
- **【分值】**：选择题2分/题；综合应用题各小问分值及总分
- **【年份】**：试题对应考研年份
- **【考点】**：核心考核知识点
