## 还需要输入，但不阻塞上述准备工作

1. **实际学习反馈**：当前逐题日志和新整科日志都为 0 条。只能说系统尚未收到记录，不能推断你没有学习。掌握度、学习前沿、复习队列暂不生成；收到真实反馈后再按协议推导。
2. **相关题的原稿或人工核对**：在要用到冲突评分、要建立统计样本时处理相关问题即可，不要求先人工审完全部 L3。
3. **正式考频统计**：需要同一目标口径的完整可见整卷，核对主统计标签、分值、原子口径及样本资格。现在尚未建立合格年份集合，F/C/V 保持 null，不把未确定年份当作零频率。方法、难度等其他 L3 字段不是共同前置条件。
4. **额外后台 API 建设预算**：金额或 token 等数值预算和实际用量尚未提供，默认暂停。预检只检查传入数据，不是账单计量器，不会为并发任务锁定额度，也不拦截工具之外的调用；不得把预检通过宣称为已自动封顶。
5. **独立隐藏测评条件**：汇总接口已经可用，独立性尚未激活。现有证据表明核心 1277 题已被 Teacher 语义阅读，不能仅移动目录就重新充作对 Teacher 隐藏的测评题。学生是否看过仍为当前未知；若以后建立独立测评，题目身份和明细应在合格的私下路径保存，不能回传到这里。

本轮沿用 45 分钟学习块、数学一与408每周共 50 小时、首个完整周 25/25、最低 15/20、维护 5 小时计入 50 小时的既有合同；不重开 9 月 2—6 日启动窗口，不生成新的个人学习状态或时间分配。
