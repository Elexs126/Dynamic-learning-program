# 概率论与数理统计正文知识点抽取批次规划 (v0)

> **规范版本**: `extraction_batches_m1_prob_v0`  
> **教材来源**: 《考研数学·概率论与数理统计·辅导讲义·基础强化一本通》（李良，含基础篇 7 章与强化篇 7 章）  
> **规划目的**: 为第三阶段逐批读取正文提供执行单元。每个批次自包含，并明确关联对应的考纲 Scope，后续正文抽取 Agent 只需携带本批 Scope。

## 一、批次拆分原则

1. **严控输入规模**：默认一章一个批次；对正文篇幅较长或题型密集的章节（基础篇第1、2、3、4、6、7章，强化篇第1、2、3、4、7章），按自然小节与题型拆分为 2~4 批，单批控制在 100~650 行之间，杜绝超大上下文输入；
2. **作用域自包含**：每个批次均提炼去重后的 `relevant_scope_ids`，后续正文抽取 Agent 只需要加载该列表，无需全量读取考纲；
3. **超纲主动过滤**：超纲内容（经验分布函数、尾部图书广告）已从抽取批次中完全排除，保证正文抽取专注入纲内容。
