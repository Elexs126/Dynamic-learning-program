# OCR 质量抽查报告：线性代数基础学习册

检查日期：2026-08-30

## 结论先行

**六章 OCR 整体不合格，不能直接作为数学学习讲义、做题文本、公式检索库或后续知识抽取语料。**

它的优点是章节顺序和页级覆盖基本完整，普通中文叙述多数还能辨认大意；但矩阵、行列式、方程组、向量下标、特征值、二次型及推导公式存在系统性失真。部分错误不是排版不美观，而是已经改变数学含义，例如负号丢失、指数改变、变量被换成另一字符、不同向量下标合并、充要条件两边变成同一个式子。

因此，当前 Markdown 最多只能作为中文关键词索引底稿。数学内容需要从原 PDF 重新做版面感知和公式感知 OCR，不能靠零星替换修好。

## 跨章节的系统性问题

1. **二维结构被压平**：矩阵的行列、行列式竖线、方程组大括号、增广矩阵分隔线、分块矩阵和行变换箭头普遍消失。
2. **上下标丢失或串位**：`x_1,x_2,x_3` 常变成 `x、2、x3`；不同的 `α_1,α_2,α_3` 会合并成同一个 `\alpha`，直接破坏题意。
3. **符号发生语义级混淆**：λ→“入”，α↔a，η→n，γ→y，0↔O；加减号可变成汉字“十”“一/二”，逆矩阵和伴随上标可变成引号或普通数字。
4. **公式被改成另一公式**：抽样中发现负号丢失、三次幂变二次幂、`a-b` 变 `a-6`、`C^TAC` 变 `CAC`、`A^*` 消失等明确语义错误。
5. **结构噪声混入正文**：页眉、页码、侧栏标题、“练习区域”和答案页码被录入正文；“练习区域”又常误作“陈习区域、绿习区域”等。
6. **题干与解析难以配对**：例号频繁丢失或粘连，如“例 5”变“例 51”，解析区常只剩“例【解】/【分析】”。

## 分章代表性证据

以下行号均对应当前 Markdown 版本。

### 第 1 章 行列式

- PDF 17，MD 44–59：三阶行列式及数值竖式的边界、行列关系和下标几乎消失；正负号被识成汉字，已经不能据此计算。
- PDF 22，MD 196–227：余子式、代数余子式和按行/列展开公式中的上下标、求和范围和指数错乱，定理公式不可用。
- PDF 26，MD 324–339：四阶行列式大面积缺失；多项式的幂和系数下标改变，连所求对象也发生变形。
- PDF 36，MD 712–723：直线方程中的变量被换错，后续系数行列式缺元素；最终答案虽保留，推导不可信。

结论：中文说明勉强可读，核心行列式内容不可用。

### 第 2 章 矩阵

- PDF 38，MD 50–89：矩阵、零矩阵和相等的中文定义大意尚在，但所有矩阵行列结构、`a_ij` 下标和加法示例均损坏。
- PDF 45，MD 280–306：伴随矩阵示例的九个代数余子式计算几乎整段丢失；逆、伴随、分数和指数均受损。
- PDF 53，MD 509–524：`P_1、P_2` 下标丢失，四个选项被压成相似字符串，无法区分。
- PDF 58，MD 658–668：`|2A^*B^{-1}|` 被改成近似普通乘积；另一个题目的已知分数和目标式上标丢失。
- PDF 69，MD 1088–1103：`|kA|=k^n|A|` 的指数变成引号，第二种矩阵解法压平，关键结果丢失。

结论：本章高度依赖二维矩阵排版，实际可用性比第 1 章更低。

### 第 3 章 向量

- PDF 70，MD 13–32：本章考点前半段有漏项，知识框图被拆成无层级词串。
- PDF 71，MD 44–63：向量分量、原向量与延伸向量的记号混淆，出现 `Q2、@m、Om` 等错误，定义不再严谨。
- PDF 73，MD 150–155：定理 3.7 的核心条件被识别成乱码，整项无法恢复。
- PDF 85，MD 438–455：三阶矩阵被打散，伴随符号损坏；两个向量组的编号和下标混乱。
- PDF 97，MD 876–904：原来的 `(a-b)^2` 被识成 `(a-6)^2`，属于明确的数值语义错误。
- PDF 98，MD 909–927：施密特正交化的向量结果和最终参数答案大面积丢失。

结论：纯文字定义可粗略浏览，但向量下标一旦损坏，定理和例题便不可可靠使用。

### 第 4 章 线性方程组

- PDF 100，MD 41–72：一般方程组、矩阵形式和向量形式均被压平，未知量下标和系数对应关系消失。
- PDF 104，MD 163–180：“例 5”误成“例 15”，基础解系符号 `η_1,η_2` 被写成普通字母/数字。
- PDF 108，MD 255–276：例 12 标题只剩数字；例 13 的二阶矩阵基本整块丢失。
- PDF 114，MD 441–479：基础解向量的首项负号丢失，使通解直接变错；增广矩阵的秩判定也无法读取。
- PDF 116，MD 528–569：通解中的分式粘成字符串，后续 `AX=XA` 的矩阵方程和系数矩阵大面积打散。
- PDF 119，MD 659–666：最终系数矩阵被压成数字串，对应方程的未知量下标丢失。

结论：中文分析句常能辨认，但解方程所需的矩阵、自由变量和基础解系不可信。

### 第 5 章 特征值和特征向量

- PDF 120，MD 18–27：知识框图失去层级，`Q^{-1}AQ=Q^TAQ=Λ` 被识成近似 `Q-AQ=QAQ=A`。
- PDF 121，MD 34–64：`Aα=λα`、`(λE-A)α=0` 的核心定义被改变；迹与行列式关系又变成无法解释的求和/乘积字符串。
- PDF 124，MD 127–137：“例 5”变“例 51”，λ、幂和矩阵幂的上标损坏，例 6 标题丢失。
- PDF 135，MD 405–435：连续行列式变换全部线性化；部分特征值虽保留，后续行变换大量缺号错号。
- PDF 138，MD 555–562：特征值证明中的多项式因式分解被改成另一表达式，推理链失效。
- PDF 144，MD 755–778：含根式的单位特征向量、正交矩阵 Q 和对角化结果几乎全部坍缩。

结论：λ 的系统性误识与矩阵压平同时存在，本章不能用于特征值计算或对角化学习。

### 第 6 章 二次型

- PDF 146，MD 43–73：一般二次型的变量、下标、双重求和和交叉项严重丢失；`x^TAx` 多处变成 `xAx`，示例多项式无法还原。
- PDF 147，MD 77–113：合同定义中的 `C^TAC=B` 变成 `CAC=B`，合同符号也被改错；坐标变换方程组失去结构。
- PDF 148，MD 123–159：标准形中的 `λ_i y_i^2` 系列几乎消失，`Q^{-1}AQ=Q^TAQ=Λ` 和 `C^TAC=Λ` 均被改写。
- PDF 153，MD 238–242：题干 `x^TAx=x_1^2-4x_2x_3` 被识成近似 `x²-42`，关键题干完全错误。
- PDF 154，MD 250–266：选择题的四个对角矩阵选项几乎全部消失，只剩选项字母和孤立数字。
- PDF 155，MD 273–310：正定示例把不同变量混为同一变量；正定判定中的等价关系、转置乘积和顺序主子式结构被压平。
- PDF 168，MD 754–780：伴随矩阵 `A^*` 的证明链中，上标几乎全部丢失或变成引号，核心恒等式不可用。

结论：二次型最依赖转置、交叉项和矩阵合同，OCR 对含义的破坏尤其严重。

## 修复建议

1. 不建议在现有文本上只做正则替换。当前问题包含整块公式漏失和二维布局丢失，局部替换无法恢复原式。
2. 重新识别正文 PDF 16–168，并把“正文文本”和“数学区域”分开处理。
3. 矩阵、行列式、方程组、分块矩阵、连续行变换应重建为 `bmatrix`、`vmatrix`、`cases`、`aligned` 等数学环境。
4. 所有 TeX 命令必须置于数学定界符中，并增加自动检查：裸 TeX 命令数应为 0。
5. 人工视觉复核全部数学密集页，优先级依次为：题干和选项、最终答案、定理条件、例题解析、知识框图。
6. 对 λ/“入”、a/α、η/n、γ/y、0/O、正负号、上下标、`A^T/A^{-1}/A^*` 等高风险字符做专项校验。
