本轮按用户明确范围处理四年全部 188 题，每年 40 道选择题、7 道综合题。逐题读取题干、本地解析，并查看 48 张引用配图。标签从题意和解法骨架核对形成；未直接将旧考点升级，未联网、调用外部接口或补造出处。

## 结果入口

`系统文件/题目标注/408_2009_2012_L3/` 内的主文件为 `question_annotations_cs408_2009_2012_l23_v1.json`。它累积保存 L0—L3，L0、L1 与既有全库 L1 对应记录逐字段一致。按 `question_id` 关联，不增加原题数量，不与旧 L1 或历史试点重复计数。

另含逐字段来源证据、评分证据、任务引用索引、知识和方法词条、同构关系、覆盖报告、校验结果及输入输出哈希清单。`cs408_2009_2012_review_v1/` 是本次逐题核对的固定输入，文件中的任务和方法只保存行为骨架，不保存题干、答案或完整算法。

## 运行

在项目根目录执行：

```bash
python3 系统文件/脚本工具/05_标注与规范校验/build_cs408_l23.py check
python3 系统文件/脚本工具/05_标注与规范校验/test_cs408_l23.py -v
```

生成新的独立快照时指定尚不存在的输出目录：

```bash
python3 系统文件/脚本工具/05_标注与规范校验/build_cs408_l23.py build --output /tmp/cs408-2009-2012-l23-review
```

脚本仅需 Python 标准库、项目既有 `build_l1.py`、`json_schema_runtime.py` 及 v1.1 两份 schema。来源、图片、核对输入或程序发生变化时，已有快照不能直接覆盖或假装复用，须重新核对并生成新版本。`check` 重新生成预期内容、校验结构和引用，再逐文件比较哈希。

本轮复用 v1.1 的累积结构与局部省略表达，不修改数学一的 schema 或脚本。数学一执行说明中“每题一个整题单元”是该批数据的特定约束；本批有明确评分细则，由本脚本执行相应校验。

- 2009 第 41、43 题及 2012 第 41 题：原文分项完整且与总分一致，采用 12 个可累加分项。
- 其他题保留整题口径；2012 第 43 题的 L3 有效总分为 `null`。合计 197 个评分单元。
- `scoring_evidence_v1.json` 保留 23 项明确分值证据和 19 条条件评分规则。该文件的分项、上限、条件得分不能与主记录再次相加；推广为核心评分单元的分项带 `promoted_unit_id`。

- 2012 第 43 题元数据为 8 分，解析七项合计 10 分。两处证据原样定位保留；不选取其中一个作为有效总分，不修改 L0。

## 局部待核对及关系边界

本批 L2/L3 没有因整类信息缺失而整体跳过的字段类型。25 道综合题没有可完整采用的分值拆分，仍完成其可判断标签并保留整题单元及现有局部评分证据。需原稿或人工确认的类型为评分单元总分、条件评分适用范围，具体是上述 2012 第 42、43 题。

`field_omissions` 中 `l3.score_units.S0.points` 表示冲突总分未决；`l3.score_units.S0.subdivision` 表示已有整题分数但细分适用范围未决。对应 `score_units` 字段为 `needs_review`；其余字段继续独立填写和校验。

242 个任务引用用于定位作答证据及 36 条本地解法直接依赖，不是额外题号或评分原子。11 个备选方法只来自本地材料；8 个同构簇覆盖 17 题，只比较这四年中的明确共同结构。空备选、空关系或 `null` 只表示所述本地范围未确认项目，不能推定不存在其他方法或库外关系。

`verified` 表示标签已依据本地内容核对，不表示人工签核或原解答正确。L0 的来源可靠度仍为 `unknown`：本地没有独立出处核验材料，未联网补查。标签状态不改变使用角色、作答日志、学生能力或测评状态。
