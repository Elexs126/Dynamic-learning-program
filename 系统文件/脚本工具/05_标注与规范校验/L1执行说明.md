## 运行

Python 3.10 或以上；只使用标准库。程序复用项目已有的规范校验器。

```bash
cd /home/elexs/Dynamic-learning-program

# 构建；相同输入会验证并复用现有结果
python3 系统文件/脚本工具/05_标注与规范校验/build_l1.py build

# 完整检查：schema、ID覆盖、逐题来源哈希、证据和重复关系
python3 系统文件/脚本工具/05_标注与规范校验/build_l1.py check

# 回归测试
python3 系统文件/脚本工具/05_标注与规范校验/test_l1.py
```

默认结果目录为 `系统文件/题目标注/L1/`。从其他目录运行时可传 `--project-root` 和 `--output-dir`。额外检查报告通过 `--report` 保存到快照目录之外。

输入或规则改变后，程序拒绝覆盖旧快照；为新版本指定新目录，例如：

```bash
python3 系统文件/脚本工具/05_标注与规范校验/build_l1.py build \
  --output-dir 系统文件/题目标注/L1_第二版
```

不需要 `--force`。旧记录和已复核内容由快照保留；不要直接改生成文件。改变规则并使用新目录，再对照证据复核差异。
