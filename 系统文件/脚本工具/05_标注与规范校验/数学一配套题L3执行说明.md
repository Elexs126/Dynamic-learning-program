# 数学一配套题 L3 初标与逐题复核

本轮范围为张宇基础30讲876题（CORE_L2优先）及张宇1000题1041题（L1_FIRST），合计1917题。结果目录：`系统文件/题目标注/数学一配套题_L3_20260929_v1/`。

本批次是初标与部分逐题复核，不是1917题全部语义精标完成。150题有逐题阅读题干后形成的复核输入，其他题只生成明确标识的候选或保留有原因的字段缺失。候选不能用于正式评分或作为已审核硬前置。结果目录的覆盖报告给出每个字段的实际状态。

## 查看结果

- `zy30/question_annotations_l3_v1.json`：876条累积L0—L3。
- `zy1000/question_annotations_l3_v1.json`：1041条累积L0—L3。
- 各来源的 `field_evidence_v1.jsonl`：原文件、行号、题块哈希、候选触发依据或逐题复核身份。
- `标签浏览.tsv`：可按题号、主知识点、方法及状态浏览的索引。
- `review_queue_v1.json`：以CORE_L2在前、L1_FIRST在后的顺序列出全部待核对字段。
- `task_index_v1.json`：已核对题内推理任务；不是新增题目或评分原子。
- `l0_type_corrections_v1.json`：明确填空占位符导致的旧L1题型误判修正，保留前后值与原文定位。

## 评分与兼容性

教辅题全部保留一个整题观察单元，分值为null，不生成小问分值。新增v1.2 schema仅扩展评分单元的not_applicable状态及对应的空分值约束，旧v1.0/v1.1规范与快照不变。L3深度只表示处理到该层；字段状态才表示完成程度。

原L1候选字段逐字保留，修正的L0题型有独立变更日志。现有学习入口要求与所选L1的L0完全相同，因此本批次保留为独立增量，未直接切换活动入口。后续发布须先衔接题型修正、语义审核状态和来源清单，再重建学习导航，不能只追加两个文件路径。

## 复跑

在项目根目录使用Python标准库：

```bash
python 系统文件/脚本工具/05_标注与规范校验/build_zhangyu_l3.py check --project .
python 系统文件/脚本工具/05_标注与规范校验/test_zhangyu_l3.py --project . -v
```

首次生成用`build`，复跑已有结果用`check`。`build --output 新目录`只接受不存在的输出目录；先在临时目录生成并校验，再完整落盘。来源、题块、复核输入或输出哈希变化时会拒绝沿用旧判断，不能自动刷新来源锁绕过复核。

`zhangyu_l3_review_v1/semantic_reviews_v1.json`是150题的逐题输入；`profiles_v1.json`是可复用词条与候选行为模板。程序禁止把仅由规则命中的字段升级为verified。源文不足、未知解法、未比较的同构及未核对的题间依赖均留有具体待复核原因。没有调用外部API、没有写入题目答案、用途角色或学生表现。
