# 数学一 L2—L3：运行与交付说明

本轮按用户明确范围完成核心真题数学一 2008—2026 年 431 题的本地语义标注。逐题阅读题干与现有解析，未上网、未调用外部 API，也未补造出处或答案。

## 结果入口

- `系统文件/题目标注/数学一_L2_L3/question_annotations_math1_l23_v1.json`：431 条累积 L0/L1/L2/L3 记录。
- 同目录 `执行与覆盖报告.md`、`coverage_report.json`：覆盖数量、整体跳过类型、需要核对的题号及字段。
- 同目录 `field_evidence_v1.jsonl`：每题原文件、行号、题块哈希及逐字段依据。
- 同目录 `task_index_v1.json`：541 个题内任务引用；仅定位任务与依赖，不是新增评分原子。
- 同目录 `label_registry_v1.json`：本轮知识与方法引用词条。
- 同目录 `isomorphic_clusters_v1.json`：28 个确认了核心结构的同构簇，覆盖 67 题。
- 同目录 `validation_report.json`、`run_manifest.json`：校验结果与复跑用输入输出哈希。
- `系统文件/检查报告/math1_l23_regression_2026-09-07.txt`：14 项回归测试的实际运行记录。

## 执行方式

在项目目录运行，使用 Python 3 标准库和项目已有 JSON Schema 校验器，无额外依赖：

```bash
python 系统文件/脚本工具/05_标注与规范校验/build_math1_l23.py check
python 系统文件/脚本工具/05_标注与规范校验/build_math1_l23.py build
python 系统文件/脚本工具/05_标注与规范校验/test_math1_l23.py --project . -v
```

`check` 验证已交付快照。`build` 在输入不变时核验并复用快照；首次生成时以临时目录原子落盘。原题、图片、复核表、脚本、规范或已有输出改变时，拒绝静默覆盖。应先复核变化，再使用新的版本化输出目录。

可通过 `--project` 指定项目根目录，通过 `--output` 指定新的快照目录。已安装项目仍需原 L1 快照及原题文件，交付包是本项目的增量交付。

`math1_l23_review_v1/` 是逐题语义复核输入，19 个 `.tsv` 文件实际使用 `|` 分隔，以避免中文步骤中的标点干扰字段。脚本不靠旧考点自动推理 L2；它装配已经逐题读取后形成的结果，并核对源文绑定。复跑不会再次调用模型，也不会在文件变更后自动沿用失效语义判断。

## 分值和空字段

全部 431 题只有整题总分，没有可核验的正式细分评分标准。按既有规范保留一个 `:S0` 整题评分单元，分值严格等于 L0 原总分。541 个 `#T01` 等引用是题意任务或推理任务，不能计入题数、独立评分或考频分母。依赖中的 `from_question_id` 和 `to_question_id` 在 v1.1 本地配置中可引用这些已登记任务。

整体跳过的是小问/步骤细分分值及相应数值归属、比例；整题目标类别归属和可观察证据仍填写。整题 `score_attribution` 说明完整主目标或综合目标，不是官方评分细则。

7 题的部分字段因原文冲突待核对，留空有逐字段原因。未受影响的主知识点、能力行为等照常保留；两道题的证据只留下已确定的任务，受影响任务留空。`field_omissions` 的 `evidence_steps.U02` 对应任务索引 `#T02`，不代表评分分值单元。

空的次知识点/软前置表示未确认额外项目；空备选表示本地没有确认另一可行机制。同构 `null` 只表示本次数学一范围内未确认匹配，不能当作全库无同构。由题干缺失而无法判断的同构字段直接省略并登记原因，与 `null` 区别保存。

前置与难度为根据任务结构核对的静态教学判断，可修订；不是学生实测能力、耗时或难度。没有添加人工审核身份。全记录仍为 `needs_review`，因为累积 L0/L1 本来保留来源可靠度未知及候选状态；具体进度以逐字段状态为准。

## 兼容性

新数据沿用相同字段体系，版本为 `question-annotation-v1.1.0`。新增的两份 `*_v1.1.schema.json` 和本脚本支持局部完成；原 v1.0 schema、旧校验器、8024 条 L1 快照和旧 50 题试点均未改动。旧校验器应继续用于 v1.0，不能拿它的拒绝结果当作 v1.1 数据错误。

这次完成的是用户指定范围的标注，不改变其他来源按需加工规则，不激活隐藏测评、用途角色、学生日志或正式考频。单一主知识点与原总分齐全也不意味着独立小问统计口径已建立。
