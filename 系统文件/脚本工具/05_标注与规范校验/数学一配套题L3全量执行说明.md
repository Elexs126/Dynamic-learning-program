## 字段含义

`verified`表示本地语义及适用条件已经核对，不代表原题排版没有瑕疵或存在人工签核。累计记录的`record_status=needs_review`保留原L0/L1来源状态，具体L2/L3完成情况应读取逐字段状态。

备选方法为空表示本轮没有确认额外可用方法；同构为null表示本轮比较范围内未确认关联，不能解释为全库没有同构。直接依赖仅记录后项实际使用前项结果的所选方法；并列小问、相同知识点、章节顺序或阅读比较不会自动成为依赖。

`score_attribution`在本教辅批次中表示整题目标类别，不分配数值分数，也不证明原题的选项或条件完整。题目原文有冲突时会同时保留源文问题，不因主标签明确就取消该问题。任务引用不是独立评分原子。难度与前置为静态教学判断，不含学生表现。

## 复跑

```bash
python 系统文件/脚本工具/05_标注与规范校验/build_zhangyu_l3_full.py check --project .
python 系统文件/脚本工具/05_标注与规范校验/test_zhangyu_l3_full.py --project . -v
```

新建快照使用`build --output 新目录`。已有目录禁止覆盖；原题、讲义、补充图、复核输入或构建器变化后，需重新核对并生成新版本。`zhangyu_l3_review_v2/`提供全部1917题复核输入、复用词条、源文锁、补充来源锁和同构簇。没有外部API调用，也不保存题目答案或完整解析。

本版是独立的数学配套题标注批次。现有活动学习入口与真题统计口径不自动改变；下游接入时应同时衔接L0题型修正与逐字段状态。
