# 学习运行工具 v1

Python 标准库实现；结构校验复用项目已有 `05_标注与规范校验/json_schema_runtime.py`。没有网络请求、外部模型调用或后台计划任务。

主入口 `learning_runtime.py`，既有合同不改，新规则叠加见 `系统文件/系统配置/runtime_policy_v1.json`。题库入口、教材导航与运行就绪度是派生视图，不是新的正式题库、E 样本或学生状态表。

```bash

```

检查逐个输入和输出哈希。正式作答日志改变也会使该时点快照过期；请在新目录生成后续快照，不能覆盖 v1：

```bash

```

新快照目录名可变化；算法、已知标注列表或运行规则发生变化则还需要修改对应版本和检测。构建不会凭空发现未来新标注版本，合并优先级固定为 L1，再覆盖数学一、408前四年、408后续年三批互不重叠的正式记录；旧50题试点排除。

## 按需找教材

```bash
python 系统文件/脚本工具/07_学习运行/learning_runtime.py --project . navigate --snapshot 系统文件/学习运行/runtime_v1 --course 408_ds --scope SCOPE_408_DS_01_01
```

课程键：`m1_calculus`、`m1_linear_algebra`、`m1_prob`、`408_ds`、`408_co`、`408_os`、`408_cn`。可用 `--batch` 查询现有批次；未知键或旧快照会报错。查询只返回已有映射，不抽取教材正文。Scope、章节、题目知识词条仍是不同层次，没有强行合并为能力字典。

## 预算预检

```bash
python 系统文件/脚本工具/07_学习运行/learning_runtime.py --project . budget-check
```

当前默认预算未知，返回 `allowed=false`、退出码1是预期保护结果。已明确预算时，使用 `--input` 传入 JSON，字段必须完整：`unit`（tokens/currency/calls）、`unit_name`、当前周一的 `week_start`、`limit`、`used`、`reserved`、`estimate`、`retry_reserve`、`max_input_tokens_per_call`、`max_output_tokens_per_call`。最后两项在非 calls 单位时可为 null；calls 单位必须填写正整数的每次输入/输出上限。tokens/calls 数额必须为整数，金额单位必须注明币种且所有数额统一。

以北京时间判断当前预算周。剩余=上限−已用−已预留，必须容纳本批预估和重试预留；到达上限停止。输入用量需由实际账单/已知记录提供，工具不验证账单真实性、不建立并发额度预留、不实际发出调用，不能代替完整计费拦截器。当前数值未知继续暂停额外后台语义建设。

## 校验和接收真实整科汇总

先根据《人工离线整科汇总填写说明》取得真实反馈，再按 `offline_assessment_summary.schema.json` 转为 JSON，随机生成 UUID 编号。以下输入路径仅为命令占位，不提供伪造作答示例：

```bash
python 系统文件/脚本工具/07_学习运行/learning_runtime.py --project . offline-check --input /实际路径/学生反馈.json
python 系统文件/脚本工具/07_学习运行/learning_runtime.py --project . offline-append --input /实际路径/学生反馈.json
```

`offline-check` 只读；`offline-append` 校验全部历史并加锁追加，同编号拒绝。原 `attempts_v1.jsonl` 不受影响。新的 JSON Schema 拒绝任何额外属性，五维固定 null，独立性固定 unverified；用户自报测评种类不自动激活独立测评。
