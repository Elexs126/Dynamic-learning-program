# 按需方法复用

2026-10-15。沿用当前考试目标、时间合同和日结入口。不把“替全库寻找最优解、统一答案、生成模板”设为开始学习的前置条件。

## 实际使用过程

1. 近期任务中发现重复操作、繁琐路线或条件混淆时，Teacher查询方法关系，阅读当前原题、已有L2和必要教材片段。保留已有参考路线，不先为每题生成“最优答案”。
2. 确有近期用途时，登记少量候选和核对依据。仅复用一步标step，完整路线才标whole。一题可关联多种方法，知识分类保持独立。
3. Teacher明确选择本次复用的方法，按当前障碍教学。用真实陌生表现和延迟保持检查效果，不因共享方法认证其他能力。
4. 候选不好用时修改、拆分、放弃或保留原路线。没有候选、没有足够收益依据或核对成本过高时，照常进入原学习循环。

这是原有按需教学的一部分，受人工维护和API建设预算约束，不增加默认后台调用或全库语义建设。

## 只读查询

```bash
python3 -B 系统文件/脚本工具/07_学习运行/daily_practice.py --project . method-report \
  --question M1-10-F-T10

python3 -B 系统文件/脚本工具/07_学习运行/daily_practice.py --project . method-report \
  --method MR_MATH1_PARTS

python3 -B 系统文件/脚本工具/07_学习运行/daily_practice.py --project . method-report \
  --knowledge M1_K_2176c89072e9f2f7
```

不加过滤时只列登记关系；按知识点查询也保留尚无方法关系的题。输出保留原L2方法及审核状态，分别列出子步骤和完整路线。缺少关联不等于不适用。查询排除当前公开角色配置禁止Teacher使用的题，不探索隐藏池，不写作答日志。

## 两个分类维度

| 信息 | 决定什么 | 不能据此决定什么 |
|---|---|---|
| 原知识点与共享能力 | 范围、观察目标、前置、复习与掌握证据 | 唯一解法 |
| 方法与题目关系 | 可能复用的步骤或路线 | 整题同构、学生掌握或全局最优 |
| Teacher本次偏好 | 同等需要下优先使用已核对关系 | 越过前沿、已知不足的硬前置或到期任务 |

目前2010年第10题、2018年第15题同时关联换元与分部积分；2018年第10题关联分部积分。三题原主知识点不同。所有关系均为step，没有覆盖读取边界等其余工作，也没有把三题归成一个完整题型。

## 接入日结

`daily-teacher-plan-v1` 的学科对象增加可选 `preferred_method_ids`，只接受库内同科方法。未提供时不按方法改变选题；Teacher仍需按真实判断设置优先知识点、能力或前沿，不会自动扩到全部相关章节。

近期确有积分任务时，可在实际Teacher计划的 `subjects.MATH1` 中加入以下字段片段，再通过原 `recommend` 或 `daily-close --teacher-plan` 运行：

```json
{
  "mode": "repair",
  "preferred_method_ids": ["MR_MATH1_PARTS", "MR_MATH1_SUBSTITUTION"]
}
```

这不是完整计划，也不是对学生当前前沿的预设。偏好仅用于repair；到期、必要任务和明确能力优先级仍先于方法偏好。关系为新鲜的checked时，在修补入口和明日建议展示共用原理、条件、边界和实际关联题。方法不进入掌握计分、不显示在试卷题面、不参与maintenance/exam抽题或给这些页面添加提示。

## 关系维护与证据边界

配置为 `系统文件/系统配置/method_reuse_v1.json`，实现为 `method_reuse.py`。方法包含名称、科目、原理、条件、边界和近期用途；关系包含题号、方法ID、题干指纹、状态、复用范围和依据。同题同方法只登记一次。

| 字段值 | 含义 |
|---|---|
| candidate | 待核对假设，不参与选题和教学展示 |
| checked | 已按公开原题核对适用关系；不是人工签认、形式证明、评分保证或个人效果证明 |
| rejected | 保留被否定路线依据，不参与复用 |
| step | 仅复用一段操作，不计完整解法覆盖 |
| whole | 已核对完整路线适用性，仍不表示最优或学生已掌握 |
| effective_status=stale | 题干指纹已变化；保留原关系，暂停使用，等待按需重查 |

参考解法、某个成本标准下的单题较优解、适合整套任务的组合没有固定升级顺序。单题稍慢的路线可能有复用价值，因此保留多个候选；没有真实学习成本时不伪造精确ROI。统一方法存在不等于额外方法冗余，不能据此删除考试范围、学习任务或评分要求。

目前没有自动解法搜索、数学核查、个人成本估计或全局优化器。已实现的是关系保存、可追溯查询、有限候选状态、明确的Teacher选择及日结接入。

旧标签转共享能力别名必须对该标签全部题目一致成立；复合题、未映射或冲突映射阻止整体替换。普通冷测按实际能力判断多样性，不能靠两个旧标签表示同一能力凑数；同题干副本不能再次算陌生题。冲突需要核对，不覆盖或自动修复历史日志。

验证继续运行 `test_*.py`。人工样本仅用于内存或临时目录；正式日志保持只追加，原题、L2/L3和历史题库快照不随方法库改变。
