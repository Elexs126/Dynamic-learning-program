# 明日练习卷与每日收尾

`daily_practice.py` 将本项目已有的活动题库、标记与真实反馈接到每日学习闭环：当天自核反馈 → 日志校验与追加 → 学习状态/到期复习/薄弱点 → 对应题目抽取 → 明日数学一与408试卷。Python标准库实现，页面内置固定版本MathJax 3.2.2，公式和原题配图离线可用；不请求模型，不重新标注题库，不保存答案。

## 给学生的使用方式

1. AI在当天收尾时交付下一天的练习入口 `系统文件/学习运行/每日练习/YYYY-MM-DD/index.html`，数学一和408分别打开。
2. 先按“明日建议”处理必要的教学准备，再作答。每题点“开始本题”，第一遍结束点“完成第一遍”，系统记录实际作答用时；也可手动修改。作答文字只存在本机草稿。
3. 完成第一遍之后，使用自己的外部权威答案核分。填写第一遍得分率、真实用时、提示等级、陌生/限时情况、可靠五维观察和复习间隔。未观察五维保持“未观察”，不要勾选未经实际满足的条件。
4. 导出自核反馈，两科各一个JSONL文件，交给AI当天日结。若浏览器没有下载文件，可用“保存反馈文件”入口，或展开复制备用反馈交给AI。AI接收真实反馈后运行下面的 `daily-close`，追加日志并生成下一天的新卷。已有聊天反馈也可由AI忠实整理为同一schema，不要求学生手工写JSON。

不读取外部答案，不把练习分数当成整科预测成绩。整科反馈仍走原来的 `offline-append` 接口，整科总分不能推出某个知识点的掌握度。页面默认不自动宣称陌生题或混合测验：需要学生实际满足并确认，部分题导出时混合条件也会校验。

## AI必须执行的日结命令

以下反馈路径为学生导出文件的占位，日期为实际结束的学习日，次日由工具计算，按北京时间截断反馈：

```bash
python -B 系统文件/脚本工具/07_学习运行/daily_practice.py --project . daily-close \
  --as-of 2026-10-05 \
  --feedback /实际路径/2026-10-05-MATH1-feedback.jsonl \
  --feedback /实际路径/2026-10-05-CS408-feedback.jsonl \
  --teacher-plan /实际路径/当天Teacher判断.json
```

`--teacher-plan`可省略。反馈已经通过其他可靠入口进入正式日志时，也可省略 `--feedback`，仅日结现有记录。执行日期默认北京时间当天。先完成所有真实反馈接收再冻结次日卷；已经冻结的日期不因新增反馈重抽，其后的反馈可进入下一次日结。相同attempt_id、相同内容的重试不重复追加，内容不同则拒绝覆盖。生成页面失败不追加反馈；若页面准备后追加成功、发布被中断，同一反馈重试会去重并完成发布。

只从现有记录生成试用卷，可指定新的预览目录，避免提前占用正式日期：

```bash
python -B 系统文件/脚本工具/07_学习运行/daily_practice.py --project . recommend \
  --as-of 2026-10-04 --output /实际路径/新的预览目录
```

工具允许活动快照中逐题/整科日志的哈希因真实反馈变化，但会重新校验当前日志；其他输入或快照损坏仍拒绝，不需要每次日结重建整个题库。

## 沿用当天已判断好的推荐规则

Teacher计划版本固定为 `daily-teacher-plan-v1`。以下为字段说明，不是学生当前能力的预设：

| 字段 | 含义 |
|---|---|
| `subjects.MATH1` / `subjects.CS408` | 两科当天判断 |
| `priority_knowledge_ids` | 按既有判断优先安排的主知识点，使用活动标注中的 `l2.main_knowledge.id` |
| `required_knowledge_ids` | 预定核心任务、必要前置，优先级高于普通薄弱点 |
| `working_knowledge_ids` | 已有可靠证据支持的工作掌握，供硬前置筛选使用，不能随意勾选 |
| `frontier_scopes` | 既有学习前沿，使用题库中完整的 `l1.official_scope_coarse` 字符串 |
| `exclude_question_ids` | 当前不宜安排的题目 |
| `mode` | 可选：repair修补、maintenance混合维护、exam考试练习 |
| `priority_ability_ids` / `required_ability_ids` / `working_ability_ids` | 对应旧知识点字段的共享能力入口，只接受已核对映射及可靠观察 |
| `preferred_method_ids` | 可选的本次复用方法，仅用于repair同等需要下的选择与入口解释；不改变知识分类、前沿或掌握证据，详见[按需方法复用](按需方法复用说明.md) |
| `practice_minutes` | 可选的次日作答预算，不超过当天该科净时间 |
| `weekly_allocation` | 可选的周审计分配，包含MATH1/CS408，合计50小时且分别不少于15/20小时 |
| `effective_week_start` | 调整周分配时必须给出目标日期所在周的周一，格式YYYY-MM-DD |

已验证主标签用于细知识点路由；只有L1的题按粗章节路由，不假装完成细能力认证。未知ID、跨科学习前沿或未知字段拒绝。没有合格E样本时不产生虚假考频/收益排序；复用Teacher已经做出的优先判断，缺失时依次处理到期题、弱项和课程顺序。认证结果保持独立性未验证，不把训练卷自动升格为FIXED_AUDIT或SEALED。

默认没有机器可读的完整能力图，因此未提供前沿时继续观察到的当前章节，不凭一次作答跳到下一章；Teacher确定新的学习前沿后传入计划即可。课程未收到任何反馈时按主教材首章开始，这只是一份学习建议，不是“学生未学”的事实判断。

## 用途、题型、题量与分值

配置：`系统文件/系统配置/daily_practice_policy_v1.json`。每天先按合同星期预算及周比例计算两科净时间，默认一半作答，一半留给教学、自核、复盘与维护。按同题型至少3个独立、陌生、限时的可比第一遍作答，使用最近30个耗时的中位数；不足3个时数学一选择/填空4分钟、大题18分钟，408选择2分钟、大题16分钟。这些是可调冷启动估计，不是已测得的个人速度。

默认周三、周六混合维护，周日考试练习，其余日期建立能力或修补缺口；Teacher可根据实际障碍指定用途。修补时允许单一题型并最多聚焦三个能力，预算是上限，不为填满时间追加无关题。混合维护只使用已观察能力；未知状态不假装已经学过。

考试练习最多一张完整真题的题量，按照比例用最大余数法取整；在时间和可用题目范围内选择能完整容纳所有题型的最大卷。下表仅为考试用途的预算示例：

| 两科合计净时间 | 单科默认作答预算 | 数学一 | 408 |
|---|---:|---|---|
| 8小时（25/25分配） | 120分钟 | 7选择＋5填空＋4解答，预计120分钟 | 26选择＋4综合，预计116分钟 |
| 6小时（25/25分配） | 90分钟 | 5选择＋3填空＋3解答，预计86分钟 | 19选择＋3综合，预计86分钟 |

考试用途的实际前沿、前置或完整题干不足时可能缩卷或明确输出不足。数学一按10∶6∶6，408按40∶7安排数量；原题分值原样保留。数学一无官方分值的练习按选择/填空5分、大题10/12分训练槽配分；408综合训练槽取项目2025真题的13/10/13/10/7/8/9分。配套题原始 `original_points=null`不改。小卷取整、不同年份及实际大题分值会造成分值占比偏差，卷面和报告明确说明；不为凑总分篡改原题分值。

为满足学生需求选择章节，而非强迫每日弱项练习机械覆盖数学60/20/20或408四门课的全卷内容比例。同卷不重复题号或题干指纹，可靠同构簇尽量不重复；学生做过的题只在到期复习时重发。保留大题全部小问；有未决或跨题上下文依赖的题跳过。优先使用近期修订的数学配套题；缺少选项、重复选项、可机械检测的公式压平/括号问题、缺图或来源越界会跳过并记录原因。该过滤不等于对全库语义正确性的再认证。

复习按能力和具体误区合并，保留历史题号；一题可安排检查多道旧题关联的同一任务，不机械重做所有原题。安排探针不等于已完成。真实反馈只更新观察到的能力，既往误区需明确核查并无提示可靠通过；未覆盖任务保留。考试用途无法组成各题型齐全的小卷时明确输出不足，修补用途则允许只交付少量针对题。

## 产物和检查

每次日结产生一个不可覆盖的日期目录：`index.html`、`数学一.html`、`408.html`、`明日建议.md`、`学习状态与明日计划.json`与输出哈希清单。页面包含真实题干、原有选项、嵌入配图、离线公式、打印样式、计时、草稿与自核反馈导出；没有参考答案或解题过程。每题具体选题原因保留在报告和计划里；教学动作和机制解释只在修补入口展示，维护和考试题面不给章节/方法提示。综合题可分别填可靠的能力得分；未观察能力留空，不从整题总分推定。

```bash
python -B 系统文件/脚本工具/07_学习运行/daily_practice.py --project . check \
  --output 系统文件/学习运行/每日练习/2026-10-06
python -B -m unittest discover -s 系统文件/脚本工具/07_学习运行 -p 'test_daily_practice.py' -v
```

本功能是日结时运行的本地流程，不是每日定时提醒或后台监控。需由当天负责学习的AI执行命令并交付页面；真实反馈缺失时保留未知，不伪造第一天成绩或进度。
