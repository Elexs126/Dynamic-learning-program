# 标注 v1.1 的局部完成支持

2026-09-07，用户明确要求完成数学一 431 题 L2—L3 中所有可根据本地文件判断的标签，并对整类缺失信息直接跳过。本次为此实现版本化局部字段支持，保持原 v1.0 文件及其旧快照哈希不变。

新版本仍为原有累积 L0—L3 字段体系，不另设一套知识标签表。`question_annotation_v1.1.schema.json` 和 `question_annotations_bundle_v1.1.schema.json` 与 `build_math1_l23.py` 的语义校验必须一起使用。

- L0、L1 仍完整保留。本次数学一记录逐字段等于已交付 L1 中的对应层。
- `annotation_depth: L3` 表示已处理到 L3，不能据此断言所有字段均已完成。
- L2/L3 的原字段名和结构不变，允许有原因地省略内容；所有字段的状态、置信度元数据仍必须保留。
- 新增 `field_omissions`。每项记录字段路径、原因类型与具体原因。省略字段必须登记；登记为省略的字段不得又写入猜测值。
- 部分证据缺失使用 `l3.evidence_steps.U02` 等任务位置，仅省略受影响任务，其他已确认步骤继续保留。任务位置对应独立任务索引 `#T02`。
- v1.1 的题内依赖允许使用 `task_index_v1.json` 内登记的任务引用，必须校验存在性、所属题号和方向。这些引用不是新 canonical 题号，不是评分原子。
- 空数组和 `null` 的本地范围含义写入执行策略及证据文件；不能将未知伪装为 `not_applicable`。
- `verified` 指标签已结合本地内容核对；不表示人工签核，也不认证原题解析正确。

仅 schema 校验无法验证跨文件来源、缺失理由、小问依赖或分数分配。本轮语义校验额外强制：恰好 431 个 canonical 数学一题号、每题一个原总分评分单元、L0/L1 保持、词条引用合法、依赖无悬空或环、同构互相引用、不包含答案或用途/学生字段、输入输出哈希一致。

整库没有细分评分证据，因此小问分值和按步骤/知识点的数值归属不创建。整题级类别归属是基于题意的结构性标注；详细阅卷分值仍不可由此推定。

正式结果入口：`系统文件/题目标注/数学一_L2_L3/`。其余题源的 v1.0 L1 继续有效；旧 50 题试点保留作历史材料，不将两份记录重复计数。消费者读取数学一新版本时应按 `question_id` 关联，并使用逐字段状态。
