## 一、设计原则与映射口径

1. **教材结构是来源定位，不等于考试结构**：
   - **大端小端与边界对齐跨章映射**：教材在第 2 章 2.3.4 中讲解了“数据的宽度和存储（大端方式、小端方式与边界对齐方式存储）”，在 408 考纲中明确列为第四章指令系统（`SCOPE_408_CO_04_01`）核心要求，同时作为第 2 章数据表示（`SCOPE_408_CO_02_01`）的物理存储形式，本规范建立跨章双向映射；
   - **多处理器体系结构归位**：考纲将多处理器基本概念（SISD/SIMD/MIMD、硬件多线程、多核、SMP）统一归入第五章 CPU 末尾（`SCOPE_408_CO_05_03`）。教材 5.7 节与此完全吻合，完整映射至 `SCOPE_408_CO_05_03`；
   - **异常与中断双重映射**：教材第 5 章 5.5（异常和中断机制）侧重 CPU 内部硬件响应与断点保存（`SCOPE_408_CO_05_02`），第 7 章 7.3.2 侧重外设 I/O 中断判优、向量中断与屏蔽字技术（`SCOPE_408_CO_06_02`），两者分工清晰且互为印证；
   - **外存与虚存跨科目映射**：教材第 3 章 3.4 外部存储器（磁盘、SSD）与 3.6 虚拟存储器，在计组侧重硬件体系实现（`SCOPE_408_CO_03_01`、`03_02`、`03_03`），同时与操作系统对应外存管理（`SCOPE_408_OS_05_03`）和虚存置换（`SCOPE_408_OS_03_02`）形成跨科目知识纽带。
2. **多对多容纳关系**：
   - 一个教材小节可横跨多个 Scope：如 2.3.4 同时涵盖数据表示（`02_01`）与指令系统数据存放（`04_01`）；3.6.5 虚存与 Cache 对比同时涵盖虚存（`03_03`）与 Cache（`03_02`）；各章末尾“本章小结及常见问题”系统辨析全章跨考点深度问题；
   - 一个 Scope 也可由多个章节覆盖：如 `SCOPE_408_CO_03_01`（主存与存储介质）被 3.1 概述、3.2 主存、3.3 CPU连接及 3.4 外存多个结构小节共同支撑。
3. **超纲严格标识（`out_of_scope_candidate`）**：
   - **外部设备具体参数彻底超纲**：第 7 章中的 `*7.1.2 外部设备`，教材原文标有 `*`，详细介绍了键盘、鼠标、CRT/LCD/LED显示器参数（分辨率/色彩深度/刷新频率/显存VRAM容量与刷新带宽计算公式）、针式/喷墨/激光打印机等。408 考纲输入输出系统仅考查“I/O接口”与“I/O方式（程序查询、中断、DMA）”，外部设备具体硬件参数考查（除2010年曾考过一次显存带宽真题外）已不在最新考纲范围中，明确标记为 `out_of_scope_candidate`，在正文抽取批次中完全隔离排除；`*7.1.3` 习题中保留的历史考题作为辅助背景记录。
4. **状态类型说明**：
   - `in_scope`: 考纲明确要求的核心考试范围；
   - `partially_in_scope`: 辅助性、演化背景或支撑工具性内容（如发展历程、各节配套习题精选与答案解析）；
   - `out_of_scope_candidate`: 考纲明确不要求的超纲拓展内容（如 7.1.2 外部设备具体硬件参数）；
   - `needs_review`: 边界存疑需进一步审定内容（当前全部明确，为 0 项）。
