# 《张宇考研数学题源探析经典1000题》全书题库总索引

> 本题库全面收录《张宇考研数学题源探析经典1000题》**高等数学**、**线性代数**、**概率论与数理统计**及**综合篇**全书题目。
> 每道题目均严格按照考研复习规范标注了 **2 个核心分类双标签**：
> 1. **【课程】**：`高等数学` / `线性代数` / `概率论与数理统计`
> 2. **【章节】**：对应具体章节名称（如 `第1章 行列式`、`第1章 随机事件与概率` 等）
> 并按照 **基础篇**、**强化篇**、**综合篇** 模块分目录存放，包含高清配图与标准 LaTeX 公式。
