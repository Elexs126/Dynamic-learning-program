# 考研数学二历年真题集（2008 - 2026）

本目录收录了 2008 年至 2026 年（共 19 年，431 道题目）全国硕士研究生招生考试**数学二**完整真题集。

## 试卷结构与科目分布

- **微积分（高等数学）**：极限、一元微分、一元积分、多元微分、二重积分、常微分方程等（约 78% / 80% 分值，不考三重积分、曲线曲面积分、无穷级数与概率论）
- **线性代数**：行列式、矩阵、向量、线性方程组、特征值与特征向量、二次型等（约 22% / 20% 分值）

## 题目标签说明

每道题目后均附有标准属性标签与可折叠参考答案解析：
- **【题型】**：选择题 / 填空题 / 解答题
- **【科目】**：微积分 / 线性代数
- **【分值】**：具体题目分值（2021年后选择题/填空题各5分，大题10/12分；2020年前选择题/填空题各4分，大题10/11分）
- **【年份】**：试题对应考研年份
- **【考点】**：核心考核知识点
